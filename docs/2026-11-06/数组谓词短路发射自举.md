# 数组谓词短路发射自举

## Intent：最终目标

把 every/some 的空值恒等结果、短路分支、循环与结果块构造迁入 RX/ZX。
保留 source、context 和 callback 的求值、错误顺序与元素存储转换，不改变目标程序。

## Data：可用证据

起点 510df494，工作区干净。predicates.zig 仍以 Native 构造完整短路控制流。
已有 Source AST 结构化表达式／语句列、块／循环构造和通用导入器，可以复用；
仅需补齐 Boolean 表达式、Branch 语句及上下文 binary 便捷构造。

现有 predicate-order、predicate-arguments、context-effects、context-borrow 目标
分别覆盖求值顺序、参数、上下文副作用及嵌套借用。无需新增测试用例。

## Edges：边界与限制

- Native 仍准备源列表、callback、context 初值和元素转换等既有叶；不假装 Lower
  或元素转换已自举，也不添加 Source 回调 Native 谓词规则的语义桥。
- 上下文在 for 外执行，包括空数组；元素转换前缀与 callback 在同一 for 作用域。
- 子块的物理语句行不能计入父块长度。Source 明确计算三个导入段与预备前缀范围。
- 不借用 Source 临时分配的文本跨 arena；输入名称来自目标 AST allocator，允许
  通用导入器借用它们，不复制已有表达式表或语句表。
- 初始 seed 保留旧算法，正式路径静态调用生成 Source；固定性能基线不重置。

## Answer：交付格式与成功标准

RX 显式连接初始化、短路构造和循环结果；ZX 实现原子 AST 构造。完整产物一致、
阶段再生成及相关现有回归通过，隔离测量受影响路径后收口全部变更并提交推送。

```mermaid
flowchart LR
    N[Native 叶与绑定准备] --> I[RX 初始化]
    I --> D[ZX 短路分支]
    D --> F[ZX for 与恒等结果]
    F --> A[Source 结构化 AST]
    A --> T[通用 AST 导入]
```

```mermaid
flowchart LR
    L[已有源与 callback 表达式] --> B[Source 只借用 ID 和名称]
    P[外层及元素前缀] --> R[Source 规划物理范围]
    B --> R
    R --> S[stop / decision / main 三段]

    O --> E[释放 Source 工作区]
```

## 实现与范围核对

RX 依次调用 initialize、decision、finish。Source 决定 every 的恒等值为 true、
some 为 false；callback 不等于恒等值时 break 相反值，否则遍历结束后返回恒等值。
空列表因此保留原结果。Boolean、Binary、Branch 均用通用 AST 列构造，未拼接 Zig。

设 Native 叶准备后的语句基址为 B，元素转换前缀直接语句数为 L，外层绑定数为 P。
目标物理布局为：

| 段       | 起点          | 行数 |
| -------- | ------------- | ---- |
| stop     | B             | 1    |
| 元素前缀 | B + 1         | L    |
| decision | B + 1 + L     | 1    |
| 外层前缀 | B + 2 + L     | P    |
| main     | B + 2 + L + P | 2    |

for.body 指向 B+1、长度 L+1；结果 block 指向 B+2+L、长度 P+2。三个 Source
表分别导入，Native 前缀直接存入目标表，不复制完整 AST，也不重新解释或选择分支。
AST 内部物理行的顺序变化不改变 printer 所遍历的词法块与目标程序执行顺序。

Native 的 fresh 顺序仍为 operand、predicate、callback/context 内部名称、元素
转换名称。Source 仅创建不含新名称的控制 AST；label/capture 均由 Lower allocator
持有，所以 appendBorrowingText 可以在释放 Source scratch 后继续安全使用。

通用 statements 列补齐 Branch payload，forms 列补齐 Boolean；既有生产者由
empty 初始化为空列，并沿结构展开保留它们。没有删除导入器的 schema、长度和
布局检查。原 Native 完整配方仅保留在 predicates/seed.zig。

## 自我复核与剩余边界

本阶段迁移完整 every/some 短路控制配方，Native 的导入段顺序是物理存储适配，
没有继续决定恒等值、停止条件或循环结果。Source 不创建新文本，借用与 arena
生命周期已按实际输入来源核对；未绕过 AST 布局和范围检查。

Native 仍负责 Lower 表达式 lowering、context 绑定、元素转换和 AST 存储，属于
明确的过渡依赖。整个集合生成器、Lower 及完整自举仍未完成，产物不动点不能
代替这些传递依赖的后续迁移。
