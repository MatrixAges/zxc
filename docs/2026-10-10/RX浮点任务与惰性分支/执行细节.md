# RX 浮点任务与惰性分支执行细节

本文采用 IDEA 框架，与执行计划和机器可核验记录共同交付。

## Intent：最终目标

补齐浮点 payload 经过 RX 顺序 Task.out、bool Switch、Return 和统一编译库的执行证据。保持 Test262 对齐与 zxc 自有特性覆盖两条目标，不把本批目录增量冒充上游适配进展。

## Data：可用证据

### 前置复核修正

只读复核发现 forward/reverse 第二次 decode 的编码缓冲使用 arena 分配，仅 free 不能证明物理释放。生成器精确进程退出 0 后、首次运行 helper 构建前，增加 decode 后缓冲污染。旧源码、旧执行输入及前后 SHA 保存在前置复核目录和前置复核.json。编译器生成输入未变，正式测试文件更新 SHA 并重新通过 AST 与排版检查。

测试编写阶段的路径拼接和字符串转义错误在运行前纠正；它们不属于实现缺陷或实际执行失败。

### 执行矩阵

源码直接生成、正向导出、逆向导出、RX 正向消费、RX 逆向消费、ZX 正向消费、ZX 逆向消费、RX 后 ZX 正向再次发布、RX 后 ZX 逆向再次发布，共九条路径。逆向路径同时反转导出表并使用 alias，避免只测试固定的导出位置。

所有库路径先保存真实 zxlib 字节、解码并污染编码存储；分析器及临时 provider 在最终生成前释放。消费和再次发布均生成真实库，不以同一源码入口伪装库路线。

每条命名用例在同一 arena 调用两次。第一次执行目录输入；第二次翻转 safe 符号位并走安全分支。随后核对首次结果与整个 guarded storage、safe 原始位模式、choose、长度和实际传入切片指针。空切片使用原始传入指针对照，不假设其等于非空存储首地址。

Debug 与 ReleaseSafe 均终态退出 0，每模式 39 步、18 个测试程序、13,608 次命名执行；合计 36 个签名测试二进制和 27,216 次命名执行。每程序的 756 个实际测试名称与目录顺序完全一致，没有仅编译而未执行的路径。

收集 548 条证据记录。独立核验已退出 0，复核冻结输入、日志、真实退出状态、测试名称、二进制 SHA 与签名，并确认两模式生成的 Zig 源码和测试源码逐字节一致。22 项静态检查与所有目录期望再次复核通过。正式专项入口为 `zig build test-rx-floating`，本次证据由同一正式 helper、emitter 与 Node runner 的冻结命令执行，不声称运行全仓库 `zig build test`。

本批没有发现实现缺陷，没有修改生产实现，也没有向实现会话发送消息。

## Edges：边界与限制

- 不覆盖浮点 Switch 标签；bool 标签与浮点 payload 是不同契约。
- NaN 仅比较分类，不证明 signaling NaN 或全部 NaN payload 的保持。
- 顺序标量任务不证明 Parallel 线程调度，也不证明 arena 借用聚合输出的跨调用寿命。
- Switch.on 是纯字段读取，本批不能独立观察 selector 求值次数。
- 1,512 是目录用例数；不同路径和模式的重复执行分别计数；两次函数调用不能再冒充两条命名用例。
- 本批没有运行 Test262 原始文件，不增加上游适配数，不代表所有特性或 Test262 全部完成。
