# 函数分析摘要所有权门禁执行记录

## Intent：最终目标

采用 IDEA 框架，为当前函数产物分析复用补齐摘要拥有、嵌套切片与生成单元独立性测试。该部分服务于 zxc 自身特性与实现可靠性覆盖，不新增 Test262 原始条目或复用案例数量。

## Data：可用证据

### 测试范围与独立预期

测试位于 `packages/test/tests/incremental/function_analysis`，共五个运行根、16 个独立命名测试。辅助 IR、Lane 与真实嵌套列表夹具按职责分开。构建采用既有 native-value-boundary 检查模块的组织方式：复制真实 genz 源码，仅在测试模块暴露内部检查入口，不修改生产导出。

| 运行根    | 命名测试 | 真实检查内容                                                                           |
| --------- | -------: | -------------------------------------------------------------------------------------- |
| summary   |        5 | 空函数表；1/17/257 有序依赖前缀；IO/process 分别传播；另一批释放后保留批仍独立         |
| lanes     |        4 | 空表；输入输出及变更/调用切片隔离；循环描述与嵌套路径隔离；源 arena 释放后副本有效     |
| resources |        3 | 标量摘要、原生能力摘要和嵌套 Lane arena 的逐分配失败清理                               |
| emission  |        2 | 交错及重复生成 entry/function/types 与单次入口逐字节一致；摘要释放后生成文本仍独立拥有 |
| buffer    |        2 | 真实嵌套列表 Program 经 Analysis.create 后路径有效；同一路线逐分配失败清理             |
| 合计      |       16 | 模式重复、前缀长度、生成顺序与 OOM 探针不增加独立用例数                                |

能力预期沿用已有 native-boundary 契约：数值原生边界的 value 资格与 IO/process 能力分开，IO/process 阻止 local value 特化。测试显式检查两类能力不互相冒出，不把内部 pure 标记误解释为没有业务副作用。

Lane 夹具使用独立初始数据。调用生产复制函数后破坏源数据，使用未破坏的另一份夹具比较全部字段；另在源 arena 退出后检查副本。真实 buffer Program 返回嵌套对象中的列表，生产分析生成非空输入与输出路径 `[0, 0]`；Analysis.create 内部工作区已释放后仍检查路径、无拒绝标记及 index-only、非 writable 能力。这将内部复制检查连接到真实摘要创建路线。

IR 夹具校验类型、函数、表达式和控制表的结构；没有通过前端分析，也不将结构校验宣称为完整语义 IR 校验。生成一致性使用简单、已经无需内联准备的有序标量 Program，验证 genz 的 prepared/analyzed 两入口与单元独立性。

## Edges：边界与限制

- 本批证明 genz 内部摘要与生成入口边界，不证明完整前端、compiler batch 调用链、应用运行语义或完整 root 已通过。
- 真实非空 Lane 覆盖借用嵌套列表身份路径；人工 Lane 覆盖复制字段，但不能替代追加、移除、更新、调用和循环路径的真实推导覆盖。
- 生成一致性比较可能共享算法错误，因此同时使用独立能力预期、源数据破坏、源释放和分配失败检查。仍不据此宣称全部生成代码语义正确。
- 不测量驻留内存、吞吐或冷/热收益，不用这些快速断言的时长评价生产编译性能。
- 固定版本专项不替代之后的生产改动回归。整体 Test262 参考对齐与 zxc 全部自身特性测试目标仍在进行。

## 自我批判

第一轮参数错误说明执行命令本身需要以工具实际接受的形式验证，不能将未运行测试误判为生产故障。第二轮虽已通过，单独测复制 helper 仍不足以证明 Analysis.create 使用正确所有权；因此补上真实非空 Lane 路线及其 OOM 门禁，再执行最终轮次。当前范围仍有明确缺口：没有在该新增内部专项运行应用，也没有证明 compiler 所有批次调用点或性能收益；这些要求不能被内部绿色结果替代。
