# 集合复制更新与原输入身份执行细节

本文采用 IDEA 框架，配合执行计划、输入身份、运行状态和独立证据核验交付。

## Intent：最终目标

忠实保留 change-array-by-copy 四份 immutable 原文的完整调用顺序和断言，为 zxc 集合不可变契约补齐新结果身份、后续调用与分配错误证据。

## Data：可用证据

### 原文与映射

锁定 Test262 缓存为 7ab7fafa0003f73fc85c1b95d88094d33f7eb8bd。四份 SHA 同时核对缓存、索引和保存原文，完整执行 sta.js、assert.js、compareArray.js 官方 harness；每份使用独立严格与非严格 context，共八次执行、二十次成功官方断言。观察包装先调用官方函数，随后复制 compareArray 的即时数组快照或记录 notSameValue 的即时身份结果。

| 原文                    | ZX 原子操作                                       | 保留的特殊步骤                             |
| ----------------------- | ------------------------------------------------- | ------------------------------------------ |
| toReversed/immutable.js | reverse 的第一个 tuple 结果                       | 首次结果丢弃，检查原输入，再调用检查新身份 |
| toSorted/immutable.js   | sort 的第一个 tuple 结果                          | 原文 0、1、2 不涉及字典序与数值序差异      |
| toSpliced/immutable.js  | splice(index,count,replacement) 第一个 tuple 结果 | 首两次插入 -1，第三次同时删除一项          |
| with/immutable.js       | with(index,value)                                 | 首两次替换 3，第三次替换原值 1 仍为新结果  |

全部登记 adapted；没有用额外生成用例掩盖原文断言，也不把对 typed list 的映射说成 JavaScript 泛型对象 API 等价。

### 目录与宿主检查

reverse、sort 各十四条，splice 一百五十二条，with 七十二条，共二百五十二条命名用例。每套包含一个完整原文实例及一个底层 allocation failure sweep。额外分区覆盖空列表、单项、顺序与乱序、重复、正负值、257/1024 长度、头中尾插入删除、无操作替换与变化替换。

四个 ZX 均只做一个集合操作，输入包含动态列表与参数；没有依用例 ID 分支，没有在被测代码中写固定期望值。全部 ZX 不超过 120 行。

宿主用 Storage 保存真实 items 与 replacement 的含哨兵缓冲。首次真实 execute 丢弃结果后立即核对完整缓冲及输入字段；第二次保留结果，检查内容和与输入两个缓冲不重叠。第三次仍复用同一输入存储，仅更新显式操作参数，再检查新结果、前次结果保持和两个非空结果互不重叠。空列表不要求新指针身份。

执行前自查发现第三次调用最初构造另一份输入缓冲，虽然值相同，却削弱原文同一接收者的前提；已在首次冻结前修正为复用 Storage。发射器额外检查 input/later 的 items 与 replacement 相等，避免后续数据修改无意改变这一前提。

逐底层失败扫描复用 checkAllAllocationFailures；arena 向受控 allocator 申请时逐一注入 OOM。每次成功或失败后核对输入；第三次失败时还复核第二次返回的旧列表。不注入标准库外部独立分配或系统故障。

## 自我批判

源码调用加包装不等于忠实适配：必须检查原文每次调用的参数、存储身份与即时观察点。首次结果丢弃不能变成未调用，with 同值替换不能丢掉身份断言。输出内容与指针不重叠是补强证据，不把它们扩展为未覆盖的 JS 对象机制。

宿主值类型与生成 ABI 指针类型必须共同核对发射器与调用点；只修一层会留下确定的编译拒绝。首次夹具失败体现该复核不足，不能归咎于编译器。

生成器三个受控参数的形式也应在动笔时落实，不能只依赖 TypeScript 或运行通过检查风格。本轮最终改为 args 对象，并用目录字节一致性保持语义；没有修改已验证的旧工作树。

原文数量、官方断言次数、预检命名执行、生成目录用例数与两模式两路径命名执行分别计数。自举模块生成完成也不能替代主语义入口的接线事实核对。
