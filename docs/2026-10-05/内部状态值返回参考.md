# 内部状态值返回参考

## Intent：最终目标

将小型纯计算状态转移拆成独立 ZX 函数，同时避免 reduce 每轮为返回对象分配 arena 内存。公开对象仍使用既有指针 ABI，应用不需要声明优化开关。

## Data：支持范围

归约回调的结果可以是一个纯 ZX 辅助函数调用。被调函数及传递调用不能使用原生接口、Store 或 Parallel；允许消费输入。返回值必须是对象，可以包含列表、字符串及子对象引用，其借用和消费仍由原有所有权规则检查。

```typescript
const initial: State = { count: 0, total: 0 }

return in.reduce((state, item) => advance({ state: state, item: item }), initial)
```

`advance` 接收旧状态并返回完整下一状态。根调用的参数允许直接传递累加器，或通过对象构造、受支持条件表达式临时引用它。普通表达式的完整累加器逃逸规则保持不变；不符合条件时使用原有生成路径。

## Edges：边界与限制

生成器为符合条件的内部函数提供返回布局值的 `callValue`。字面对象返回直接生成布局，返回已有对象时复制其布局字段。仅当输出后代类型不包含临时参数或局部对象的根类型时，才将该根对象放在栈上；可能经输出逃逸时继续使用 arena。列表元素和子对象不会因根布局返回而自动深复制。旧状态在调用成功后整体替换，错误仍按既有顺序传播。正常契约验证和 requires 检查不跳过。

公开 `execute`、内部既有 `call`、宿主 Input/Output 类型仍保持原契约。`callValue` 是生成器内部使用的实现入口，不建议宿主绑定它。空归约仍返回初值，非空归约在最终结果边界保留普通对象分配。

此优化并不保证被调函数体完全无分配：局部对象、列表、字符串、未匹配的返回表达式和其他内部操作仍可分配。数字扫描的受支持路径已观察到每字节分配消失，不将该结果推广为全部自举程序零分配。OOM 的发生时点可能因分配减少而改变。

## Answer：使用与证据

完整示例见 [数字扫描草稿](自举词法扫描/scan_number.zx) 与 [状态转移](自举词法扫描/number_step.zx)。后者用延迟确认小数点代替前瞻，把累加器保持为扁平对象。

```sh
zxc build docs/2026-10-05/自举词法扫描/scan_number.zx --out build/scan_number
zxc build docs/2026-10-05/自举词法扫描/scan_number.zx --mode lib --out build/scan_number_library
```

当前扫描的 95 个既有数字样本全部一致，执行记录见 [值返回样本](自举词法扫描/值返回样本执行结果.json)。独立 Zig 宿主执行导出的扫描模块，输入分别为 64、4096、65536 字节，arena 容量均为 72 字节，见 [内存观测](内部状态值返回/优化后内存.jsonl)。相比上一版，数字扫描源码的状态组织也同时简化，因此前后数据体现两项改动的共同效果。

调用目标的值返回资格进入生成缓存指纹。被调函数从纯计算改为依赖原生、Store 或 Parallel 后，相关调用者必须重新生成，不能继续调用已经消失的内部入口。一般函数体改变仍不强制所有调用者重生成。

实现边界与自我复核见 [实施记录](内部状态值返回实施.md)。完整编译器核心与 stage 1/2/3 自举仍未完成。

含引用状态的后续验证见 [引用状态值返回记录](引用状态值返回/实施.md)。列表跨 helper 追加的容量复用是另一项独立优化，见 [跨函数列表追加参考](跨函数列表追加参考.md)。
