# 原生清单标志回归计划

## Intent：最终目标

将公开 pkg inspect 测试对齐新增的 IO 和进程参数标志，验证五个原生实现标志的独立性、默认值和 YAML 类型边界。

## Data：可用证据

全量 Debug 结束于 4988/5007 构建步骤成功，8 个运行器失败，Zig 用例 70462/70462 通过。前七个运行器的 RX 旧夹具已专项修复；剩余 inspect_test 旧期望未包含 io_argument、process_argument。manifest/native.zig 明确解析这两个 boolean，modules/interface.zig 明确五个标志默认 false。

## Edges：边界与限制

只修改测试与测试构建输入。保留结构全等及精确诊断断言，不删除新增输出字段以迁就旧预期。本组验证清单解析和公开 JSON 输出，不代替原生调用时参数位置的运行时验证。

## Answer：交付与成功标准

将五标志的缺省/false/true 组合放入独立夹具，穷举 3^5=243 种输入。既有三标志八种全显式组合被包含，同时扩充新标志的 quoted boolean 与非法裸字拒绝。公开 inspect 全组通过后提交推送，再运行修正后的完整测试包。
