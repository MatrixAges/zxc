# 归约累加器所有权参考（历史消费语义）

> 2026-10-06：普通值已统一为不可变语义，本文关于独占输入、消费后失效及借用列表不可更新的约束已废止。本文保留历史设计与验证记录；当前契约见 [不可变输入参考](../2026-10-06/不可变输入参考.md)。

## Intent：最终目标

使用 `reduce` 逐步更新独占列表，并将最终结果继续传给消费式列表操作。

## Data：可用接口

`source.reduce((accumulator, item) => expression, initial)` 根据初值的实际所有权检查累加器。新建列表和由标量 `map` 创建的列表可以作为独占初值；函数输入中的借用列表不能直接被消费。源元素仍只读，回调仍禁止捕获外部绑定。

消费式列表操作返回元组。使用整数常量索引选择字段，例如 `items.push(value)[0]` 取更新列表；索引适用于任意元组字段，越界或动态索引在编译时拒绝。

## Edges：边界与限制

- 源列表在归约期间被借用，初值表达式不能消费同一来源。
- 空源列表返回初值，初值移入后不能再次消费。
- 回调如果返回借用值，编译器同时检查后续迭代能否接受借用累加器，不能在下一轮继续消费它。
- 元组中的引用字段沿用整个 owner 的移动规则，不提供独立字段的部分移动。
- 普通 `push`、`concat` 等仍分配并复制槽位；重复增长可能为平方时间。满足只追加且无累加器逃逸条件的 reduce 已支持 [局部容量复用](归约追加生成参考.md)。
- 普通导入函数的 Input 默认借用；需要跨函数转移时使用 [显式 owned Input 签名](显式输入消费参考.md)。仍无一般循环语法。

## Answer：用法与实际结果

[展平示例](归约累加器所有权/示例/flatten.zx) 的核心表达式如下，随后调用 `reverse`，展示返回值仍能被消费：

```typescript
const initial: u64[] = []
const flattened = in.reduce((items, row) => items.concat(row)[0], initial)

const [reversed, _] = flattened.reverse()

return reversed
```

[栈示例](归约累加器所有权/示例/stack.zx) 先用标量 map 建立独占初值，再按输入步骤执行 push 或 pop。逻辑由输入数据决定。

```sh
zxc build docs/2026-10-05/归约累加器所有权/示例/flatten.zx --out /tmp/flatten
/tmp/flatten '[[1,2],[],[3,4]]'

zxc build docs/2026-10-05/归约累加器所有权/示例/stack.zx --out /tmp/stack
/tmp/stack '{"seed":[1,2],"steps":[{"push":true,"value":9},{"push":false,"value":0},{"push":true,"value":4}]}'
```

结果分别为 `[4,3,2,1]`、`[1,2,4]`。完整运行记录包含空输入，见 [运行结果](归约累加器所有权/运行结果.json)。实现与权限流见 [IDEA 实施记录](归约累加器所有权实施计划.md)。
