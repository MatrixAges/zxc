# 枚举证明参考

## Intent：使用目标

对包含枚举输入、相等比较及分支选择的纯函数执行形式化验证，包括调用其他ZX模块后形成的库依赖闭包。

## Data：支持范围

```zx
export enum Mode { First, Second, Third }

export type Input = Mode

export type Output = Mode

export default function (in: Input): Output {
  return in == Mode.First ? Mode.Second : in == Mode.Second ? Mode.Third : Mode.First
}
```

```sh
zxc verify main.zx --solver /path/to/z3
zxc build pkg.yaml --mode lib --out dist/library --solver /path/to/z3
```

枚举可作为输入或静态对象、元组字段，支持枚举常量、相等与不等比较、条件分支及已有纯函数调用。现有契约检查继续执行，不因输入是枚举而跳过。

## Edges：边界与限制

枚举与整数仍是不同类型，不能因此对枚举执行任意整数运算。不同枚举的名义类型身份沿用前端规则。证明范围仍不包含Store状态与未知外部调用语义，也不扩展字符串等其他类型。

实现将成员索引编码为最小非零位宽，并约束输入不超过最后一个成员。三成员枚举不会把第四个位编码当作合法输入；单成员枚举仍有一位并只允许索引零。该编码仅用于编译期证明，不改变程序公开类型或运行时枚举接口。

## Answer：结果与复核

命令成功表示现有证明范围内的可达路径、安全义务及契约通过，不是任意业务意图的完整证明。失败继续输出反例或不支持原因。具体实施与实际验证范围见[枚举证明实施记录](枚举证明实施记录.md)。
