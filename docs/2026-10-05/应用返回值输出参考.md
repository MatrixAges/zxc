# 应用返回值输出参考

## Intent：最终目标

独立命令行应用可直接管理 stdout，同时保留原有 JSON 入口的默认行为。

## Data：用法

```sh
zxc build main.rx --out app --result discard
zxc build main.zx --out app --result json
```

省略 --result 时等同 json。json 将业务返回值写为一行 JSON，void 写 null。discard 执行业务后结束，不将返回值写到 stdout。

## Edges：边界与限制

discard 不吞错误、不屏蔽业务 stderr，也不禁止业务 stdout。输入仍按已有规则解析：非 void 输入一个 JSON 参数，void 且需要 process 能力的入口可读取原始参数。此选项仅用于 build app，不能用于 lib、compile、fmt、lint、verify 或 fpga。重复选项与未知值拒绝。

策略在编译期决定，生成产物缓存包含策略身份；库 execute 契约不受影响。

## Answer：交付与验收

选项贯通普通与 State 入口，watch 复用同一构建选项。普通与 State 入口、参数拒绝及热缓存已实际验证；结果记录在[实施计划](应用返回值输出实施计划.md)。
