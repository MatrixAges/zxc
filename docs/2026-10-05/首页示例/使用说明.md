# 首页示例使用说明

## Intent：最终目标

用完整结算流程演示 ZX 函数、RX 类型推导、服务组合和条件分支；独立展示有前置条件的算术契约。

## Data：可用证据

本目录包含首页引用的全部源码。`checkout.rx` 与 `order.rx` 已分别通过正式 CLI 构建为原生程序，三组输入和实际结果保存在 [执行结果](执行结果.json)。契约求解证据由 CLI 写入 [SMT 查询](bounded_discount.smt2)、[前提结果](bounded_discount.smt2.preconditions.result.txt)、[违例结果](bounded_discount.smt2.result.txt) 和 [源码映射](bounded_discount.smt2.source.json)。本次求解器为 Z3 5.1.0。

## Edges：边界与限制

这是组合语义示例，不是完整电商支付系统。金额按整数单位处理，使用 u64；示例没有为任意超大商品金额提供溢出前置条件证明。优惠规则为 SAVE10 减去小计的十分之一，整数除法向下取整；折后金额至少 10000 免运费，否则 remote 运费 1500，其他地区 600。

`bounded_discount.zx` 与结算使用的 `discount.zx` 是不同的函数。它只证明给定前提下的减法安全和输出上界，不能据此声称整个结算流程已证明。求解器需要单独提供；本次环境中 z3 不在 PATH，实际验证使用已有安装的绝对路径。

## Answer：构建与运行

在本目录运行，确保 zxc 位于 PATH：

```sh
zxc build checkout.rx --out build/checkout
zxc build order.rx --out build/order

./build/checkout '{"items":[{"price":4500,"quantity":2},{"price":3000,"quantity":1}],"coupon":"SAVE10","region":"remote"}'
./build/order '{"items":[{"price":4500,"quantity":2},{"price":3000,"quantity":1}],"coupon":"SAVE10","region":"remote"}'
```

对应结果为 `{"payable":10800,"shipping":0}` 与 `{"free_shipping":true,"payable":10800}`；JSON 字段顺序不影响语义。

| 商品小计 | 优惠码   | 地区   | 应付总额 | 运费 | 免运费 |
| -------- | -------- | ------ | -------- | ---- | ------ |
| 12000    | SAVE10   | remote | 10800    | 0    | true   |
| 2000     | 空字符串 | local  | 2600     | 600  | false  |
| 2000     | SAVE10   | remote | 3300     | 1500 | false  |

如 Z3 已在 PATH：

```sh
zxc verify bounded_discount.zx --solver z3 --out bounded_discount.smt2
```

否则把 `z3` 替换为求解器可执行文件的实际路径。成功要求前提可满足、违例不可满足，保存的结果分别为 sat 与 unsat。
