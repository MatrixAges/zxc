# 功能参考索引

## Intent：最终目标

按使用任务定位 zxc 的功能说明、接口和可运行示例。此页对应 2026-10-05 的实现，用于区分功能入口与实际支持范围。

## Data：可用证据

入口依据当前 CLI、标准模块清单和各功能参考文档；首页完整源码及运行结果见 [首页示例](首页示例/使用说明.md)。源码接口是参数与返回类型的依据，历史计划不构成功能完成证据。

## Edges：边界与限制

zxc 仍处于实验阶段，自举迁移尚未完成。标准库参考 Node.js 的功能组织，但不是完整 Node.js API 或行为兼容层。外部模块静态联结，不提供专用的运行时插件加载器；NAPI 动态库由 Node 宿主加载。编译期语义检查不等于所有应用都已形式化证明，生成 SystemVerilog 不等于已经完成 FPGA 上板验证。

zero runtime 指不引入语言解释器或通用语言虚拟机；操作系统 I/O、线程和 Node ABI 仍需要宿主设施。zero copy 适用于可以复用的值与所有权路径，不代表 JSON、编码、网络与宿主边界完全没有分配或转换。具体约束以各功能参考为准。

## 自举迁移

[完整词法扫描](完整词法扫描参考.md)已接入[正式主词法入口](正式词法前端参考.md)，跨函数列表增长和状态返回优化也已落地。宿主种子与正式入口核对了 837 份既有源码，词法模块再生成逐字节一致。语法迁移所需的[标量 token 与换行元数据](语法词法元数据参考.md)已接入生产扫描器。Parser、语义分析、后端及 CLI 迁移仍未完成，不能据此认定完整自举完成。
