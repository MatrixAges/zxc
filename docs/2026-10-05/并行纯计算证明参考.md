# 并行纯计算证明参考

## Intent：最终目标

为独立纯计算 Parallel 检查函数契约与算术安全，发布可供其他 ZX/RX 程序消费的带契约库，并生成纯函数硬件电路。

## Data：可用证据

可运行入口为 [main.rx](并行纯计算证明/示例/main.rx)，包含嵌套 Parallel、带契约函数和无 out 的调用。验证过程与反例见 [实施记录](并行纯计算证明实施计划.md)，基本语法见 [并行调用参考](RX并行调用参考.md)。

## Edges：边界与限制

分支必须满足编译器的独立性和纯度检查，不能调用 Store 或原生 external。证明支持 bool、枚举、定宽整数和后端支持的对象、元组；动态列表、字符串、浮点等仍受既有证明类型限制。

输入按声明顺序计算，全部输入成功后才进入分支。所有分支均检查安全与契约，包括没有 out 的调用；只有全部成功才能继续后续语句。证明不覆盖线程资源充足、操作系统调度和锁实现。FPGA 后端生成相同纯值关系，不承诺每个分支独占硬件单元。

## Answer：命令与成功标准

将下列 `z3` 换成求解器可执行文件路径；命令在仓库根运行：

```sh
zxc verify docs/2026-10-05/并行纯计算证明/示例/main.rx --solver z3 --out parallel.smt2
zxc fpga docs/2026-10-05/并行纯计算证明/示例/main.rx --solver z3 --out parallel.sv
zxc fpga docs/2026-10-05/并行纯计算证明/示例/main.rx --solver z3 --clocked --out clocked.sv
zxc build docs/2026-10-05/并行纯计算证明/示例/pkg.yaml --mode lib --solver z3 --out docs/2026-10-05/并行纯计算证明/消费/pkgs/proven-parallel
zxc pkg install docs/2026-10-05/并行纯计算证明/消费/pkg.yaml --offline
zxc build docs/2026-10-05/并行纯计算证明/消费/main.zx --project docs/2026-10-05/并行纯计算证明/消费/pkg.yaml --solver z3 --out consumer_app
./consumer_app '{"enabled":false,"value":255}'
```

成功时证明报告 verified，生成 SMT 及求解记录；硬件生成 SystemVerilog 与端口清单；消费端输出 `{"enabled":true,"value":255}`。库发布沿用统一库协议，调用结构和契约保存在库 IR 中，消费方仍经过证明门禁。

若无 out 分支违反契约，也必须拒绝证明、硬件生成和库发布。不能删掉无输出调用、关闭契约或把它当作死代码来取得成功。
