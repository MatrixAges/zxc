# 新增编译目标实施计划

## Intent：最终目标

将用户更新目标中的 SIMD 汇编优化（原文 SMID）、WASM 支持、参考 napi-rs 的 N-API 插件支持纳入整体实现与自举前核对。保留全部原有需求。

## Data：可用证据

2026-10-05 用户先后更新目标，明确新增以上能力。实施前检查当前 genz、CLI target、原生接口及 app/lib 发布契约，再核对 WebAssembly、Node-API 与 napi-rs 官方实现依据；目前不把 Zig 可选 target 的存在视为这些功能已经完成。

## Edges：边界与限制

保持静态类型、zero runtime 与分包职责。SIMD 需区分自动向量化证据与显式向量操作；WASM 需明确宿主导入导出和可执行证据；N-API 插件需采用宿主规定的 ABI 与生命周期，不把动态语言宿主的必要适配误称为无成本，也不另建 zxc 解释器。详细范围按当前实现与官方契约进一步拆解。

## Answer：交付与成功标准

分别形成实施方案、对应编译与发布入口、实际宿主消费产物及 usage/reference。完成证据必须覆盖实际 SIMD 汇编、WASM 宿主执行和 Node 加载插件；不能只凭构建成功或模板存在认定交付。本轮仅记录目标，尚未开始这三项新增实施。
