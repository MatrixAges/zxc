# SIMD 构造成本优化

## Intent：最终目标

定位并消除 c66012d2 后真实 SIMD 小输入冷生成的新增成本，保持 RX/ZX 循环构造和
全部语义，不回退原生规则。完成优化后重新验证并提交推送；整个编译器自举仍继续。

## Data：可用证据

上一阶段五对冷中位数 9.656→9.966 ms，热基本相同。复用原始 time -l 日志发现
冷指令退休数中位数 201795136→204076359，热 160684314→161041233，说明除了
墙钟波动还有可定位的工作量增加。输出、输入、工具链和生成缓存边界已固定。

## Edges：边界与限制

- 临时局部计时只用于归因，区分准备、ZX 构造、表达式导入、语句导入和 arena 容量。
- 不改优化级别、线程数或输出集合，不复制源码入口制造负载，不重复同版挑样本。
- 移除探针后再做正式对照，保持 source/literal/cache read、fresh 和捕获语义。
- 必需的名称/参数拥有权不能直接删除；既有输入/AST 不复制，避免新数据无谓复制。
- 不新增测试，复用真实 SIMD 夹具、现有行为与阶段构建，记录未证明项。

## Answer：交付与成功标准

交付可复核的成本归因、最小通用优化及前后完整产物/CPU/RSS/耗时证据。保留 RX
真实编排及 ZX 构造，按完整可用优化职责验收，英文提交推送 master。

## 成本归因与实现

在三个既有 SIMD 夹具中，20 次循环构造共创建 880 个表达式，其中数学计划节点
66 个。原来每次 header 调用传入并返回全部表达式列描述符（约 776 字节），而
header 实际只更新 tags、offsets。这里复制的是描述符，不是底层已有 AST 数组。

将表达式和语句 header 的输入输出缩到这两列，完整构造器只合并一次表描述符。
失败分支仍返回原表；ID 上界、payload 偏移和顺序保持一致。生成源码复核确认
两类 header 的 push 仍保留唯一增长路径，没有复制列表前缀。

宿主桥使用已有 executeValue，直接取得按值输出；将表达式的切片视图逐字段投影
到栈上描述符，再交给原有 owning importer。省去两次结果装箱，字段赋值仍经过
Zig 类型检查，嵌套切片仍在 scratch 释放前由 importer 复制到目标所有者。

| 局部探针累计指标       | 原实现 | 缩小 header | 再去除装箱 |
| ---------------------- | -----: | ----------: | ---------: |
| ZX 构造耗时 / ns       | 348291 |      295043 |     281833 |
| 表达式导入耗时 / ns    |  41581 |       41874 |      40126 |
| 语句导入耗时 / ns      |  26627 |       26584 |      25124 |
| arena 容量累计 / bytes | 513404 |      338664 |     316584 |

这是同一真实输入的归因样本，构造耗时约减少 19%，累计 arena 容量约减少 38%；
它们不能换算成整体编译提速或峰值 RSS。临时探针已全部移除，正式性能另行测量。

```mermaid
flowchart LR
    T[完整列描述符] --> P[pick tags / offsets]
    P --> H[ZX header 增长两列]
    H --> C[构造器合并一次完整结果]
    C --> V[executeValue]
    V --> S[栈上切片描述符]
    S --> I[owning importer]
    I --> A[编译器 AST 所有者]
```

## 正确性验收

- 编译器现有 372 项检查通过；现有 SIMD 目标驱动 378 个行为检查通过，应用模式
  为 safe，覆盖 Node、WASM baseline / simd128、尾部与 fallback。
- 三个原有夹具生成的 Zig 与日志共 6 个文件与优化前逐字节相同。
- stage1→stage2→stage3 自编译及正式 CLI 构建通过；stage2 与 stage3 的 1701 个
  生成文件逐字节相同，仅排除表征输入指纹的 `.zxc-inputs`。
- 本次修改的 ZX 格式检查通过；没有新增测试文件或永久性能探针。

## 正式性能与边界

移除探针后，ReleaseSmall、resident=0、同工具链和冻结输入下各取五组，按版本
交替顺序测量，没有重跑择优。大输入包含 1653 个源文件；小输入为原有三个 SIMD
夹具。大输入两版本和小输入三版本的所有冷输出一致（分别 1574、12 个文件，排除
输入指纹），每个版本的冷/热输出含指纹全部一致。另有七项磁盘、resident、语义
编辑、恢复及新增公开 ZX 根的缓存对照通过。

| 五组中位数             |  优化前 |  优化后 |
| ---------------------- | ------: | ------: |
| 大输入冷 / ms          | 708.805 | 713.145 |
| 大输入热 / ms          | 547.333 | 545.302 |
| 大输入冷 CPU / s       |    3.30 |    3.29 |
| 大输入热 CPU / s       |    2.24 |    2.23 |
| 大输入冷峰值 RSS / MiB | 363.938 | 356.781 |
| 大输入热峰值 RSS / MiB | 326.484 | 326.156 |
| 小输入冷 / ms          |   9.687 |   9.759 |
| 小输入热 / ms          |   8.747 |   8.784 |
| 小输入冷峰值 RSS / MiB |  15.438 |  15.547 |
| 小输入热峰值 RSS / MiB |  13.125 |  13.094 |

冷指令退休数大输入 45174728822→45120871445，小输入
204214789→203641438；热指令数基本持平。局部构造成本确有下降，但整体墙钟
差异小，不能据此宣称整轮编译提速。小输入 CPU 秒被系统计时舍入为零，因此
没有把它当作 CPU 收益证据。

同轮原生循环参考版本（884ee215）的小输入冷/热为 9.821/8.719 ms，冷/热指令
202477537/160679939；优化版为 9.759/8.784 ms，203641438/161128387。
墙钟没有复现上阶段 0.31 ms 的冷增加，但指令数仍多，不能宣称自举构造的全部
额外工作已消除。后续仅在实际负载再次暴露可定位瓶颈时继续优化，不重复采样挑数。

原始证据在 `/tmp/zxc-simd-cost/`：`profile*-summary.json`、
`performance/summary.json`、`positive/performance/summary.json`、`counters.json`、
`output-comparison.json`、`fixedpoint.json`、`cache-checks/summary.json` 与构建日志。

## 自我核对

本次没有迁回原生构造、没有改变 RX 编排、没有添加运行库或未检查的类型转换。
缩小描述符及去掉装箱是通用成本消除，不依赖夹具名称或固定节点数。已有行为、
产物与缓存检查均通过；仍未新增证明“错误捕获包裹 SIMD map”组合的专门用例。
