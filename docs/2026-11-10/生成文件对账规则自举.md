# 生成文件对账规则自举

## Intent：最终目标

将生成文件的changed/aligned、旧路径懒索引、wanted集合及stale判定迁RX/ZX，
保留既有IO顺序、增量稳定写出及成本模型，Native保留平台IO与初始seed。

## Data：可用证据

mirror按位置比较旧路径及hash，仅首次位置不匹配才建立旧路径索引；同路径重复
记录的按位命中保留该位置hash，按名查询取最后一次。aligned由长度及位置决定，
与hash是否变化无关。无manifest逐项walk，跳过非文件及.zxc-inputs；有manifest
仅处理旧清单路径，不额外保护fingerprint。写入完成后才收集和删除stale，最后发布清单。

当前完整129.79秒/198.51 CPU秒/2133442560 B单体/2143338496 B树峰；固定完整基线
仍129.74秒/216.03 CPU秒/2075033600 B/2247294976 B。

## Edges：边界与限制

不批量复制walker路径；Source谓词借用当项路径，零临时分配。快路径不建索引；
路径字节始终借用，Source只管理列头/索引/changed位置。旧manifest解析、目录父
缓存、并行hash/写出及最终manifest序列化仍为过渡Native，不宣称全部写出已自举。
wanted仍在全部Writing完成后才创建，IO调用顺序保持；批量选择的OOM可能早于
原逐项决策，应明确
记录这一限制，不声称精确保留所有OOM之间的优先级。不新增持久测试。

## Answer：交付与成功标准

```mermaid
flowchart LR
    Input[当前路径hash及旧清单] --> Select[ZX按位选择及懒索引]
    Select --> Changes[changed及aligned]
    Changes --> Write[既有IO写出并join]
    Write --> Aligned{顺序一致}
    Aligned -->|否| Index[ZX构建wanted]
    Index --> Stale[ZX逐项stale谓词]
    Aligned -->|是| Publish[原清单发布]
    Stale --> Publish
```

```mermaid
flowchart LR
    Borrow[借用路径及hash列] --> Arena[Source临时owner]
    Arena --> Changed[changed索引]
    Changed --> IO[原并行写出]
    IO --> Wanted[独立wanted owner]
    Wanted --> Walk[原walker或旧清单]
    Walk --> Predicate[零分配Source查询]
    Predicate --> Remove[收集完成后删除]
```

验收同输入全产物、no-op时间戳、合法编辑/恢复/陈旧文件及首次walk边界，核对
实际Source调用和生成体成本、阶段/固定累计性能，再提交推送所有变更。

## 实现及职责边界

plan.rx用标准单原子操作简写调用select：本职责是一项完整的有序集合选择算法，
不是把跨阶段业务流程隐藏到ZX。index负责通用路径→行号索引，stale负责只读查询。
Native镜像流程在原IO位置分别调用，尚未搬到RX；没有宣称整个mirror编排已自举。

select按位命中优先，只有失配才调用index(previous_paths)，索引保留最后同名行号，
再读取原u64 hash。工作列平铺，不将两个索引装进同型嵌套产品。wanted从当前位置
路径构建，路径字节借用；stale在零容量FixedBufferAllocator下执行，不复制walker
临时路径，只在原收集器命中时dupe。旧manifest解析、manifest格式及删除策略未改。

两处allocator由调用方workspace提供，Owner在对应IO阶段结束后释放；Source列
底层数据在使用期间有效，公开接口只借用输入，不能把临时列或walker路径逃逸。
seed保留原Native规则；Source正式工具不通过seed执行选择和stale判定。

## 自我复核

批量select在print/创建父目录前完成，OOM与某个父目录错误的相对优先级可能变动，
不能描述为精确保留每个失败点。wanted没有提前，全部Writing join后才建立；所有
stale收集成功后才删除，坏manifest不降级回退，正常IO及遍历/删除失败边界保留。

当前阶段迁移纯对账规则与索引状态；manifest十六进制解析、父目录缓存、manifest
序列化、IO调度及Native ABI适配仍待迁移。Source集合索引的nullable桶表示与Native
Map不同，虽算法同为稀疏查询，必须以实际生成路径测量接受，不能仅凭结果等价。
完整自举仍需入口传递依赖和stage 1/2/3验收，当前阶段不能代替。

本地日志、诊断、指标在忽略目录output-reconcile及partition-reference，均不提交。
