# 名义来源状态自举记录

- **Intent：** 撤除名义来源生产的专用 Writer，保持普通 RX/ZX 状态与静态缓冲实现。
- **Data：** 正式源码差异、既有消费者审计、生成调用闭包和专项日志。
- **Edges：** 不修改 seed 行为，不新增测试，不运行全量测试；宿主仍负责标准容器与字符串生命周期。
- **Answer：** 正式实现、可复核源码镜像、构建和专项结果，以及明确的剩余边界。

## 所有权与失败契约审计

旧 Storage.append 在每行统一扩容后追加五列，OOM 可保留先前完整行。实际正式消费者 native_artifact 在失败时释放完整 arena；未发现依赖部分追加结果的契约。新路径失败回滚五列到原长度，保留可复用容量，避免生成器依次 push 时暴露半行。

一次复制来源字符串、多行共享的成熟先例是 resolving/host/commit.zig。Storage 不按行释放字符串，因而该方式符合现有生命周期。先为 names 预留容量，再执行 data.copy；之后没有可失败步骤。无新增行时不复制字符串。

## 实施

RX 调用一个名义类型集合算法并返回 Bindings。ZX 按 kind 选择、从 first 遍历并追加四列。宿主只绑定四个标准 ArrayList 缓冲区，处理 ABI、字符串生命周期及名称借用。旧 origin_writer 的源文件、接口声明、构建注册和生成器依赖均撤除。构建与既有专项结果待填写。

## 原型核对

最初草稿有两项语法误用，已修正：push 返回元组，列取第 0 项；loop 回调不可捕获外层 in，因此 kinds 与 origin 显式进入 loop 状态。未改变编译器去迁就草稿。

原型编译成功，executeBuffered 的传递闭包包含 4 个函数，描述符 create 为 0；4 个缓冲通道按字段匹配，无旧前缀复制。普通指针入口保留通用 ABI 包装，不以全文件无分配作为结论。

## 已有专项结果

四组既有专项共 18 项全部通过：来源身份 10 项、来源分配失败 2 项、原生链接 4 项、原生链接分配失败 2 项。专项使用本轮生成模块进行编译，没有新增测试用例，也未执行全量测试。

独立只读复核未发现实质问题，核对了 defer/errdefer 顺序、失败中间列长度、单批次字符串共享和 RX 单一集合算法边界。该复核以有效 TypeTable、调用前五列对齐的既有内部契约为前提。

## 自我批判与剩余边界

本轮撤除的是正式路径的来源选择/状态写入桥。容器资源持有与字符串长期拥有仍由 Zig 宿主管理；seed 保留原有引导路径，不能由此宣称编译器已经完整自举。原型的无描述符分配证据也不能推广到普通 ABI 入口或整个编译过程。正式构建曾被会话中断终止，已确认旧进程句柄缺失后重新执行，重新构建 exit 0，36/36 步成功。
