## Intent

迁移前先解决跨导出调用保留状态容量的实际能力缺口，不以扩大 arena 或新增专用 Writer 规避。

## Data

已生成草稿 capture.zx 的普通 Zig：根入口只有 execute；两列追加分别使用 allocator.alloc 与 memcpy 复制全部旧前缀，返回 Facts 还执行 allocator.create。即便延长 arena 生命周期，重复调用仍会反复复制已有事实。

现有 genz 的模块函数已经具有 callValue 与 callBuffered；缓冲协议使用普通 std.ArrayList、started 标志以及已有来源和别名审计。常规根声明只生成 execute，没有分析根函数缓冲通道。

## Edges

保留 execute 的签名和行为。新根接口必须复用函数级 lane 来源、重复路径、旧版本、契约与并行拒绝规则；不能给 refinement 单独放行。原生调用者传入缓冲时必须拥有对应输入前缀，不能在消费更新后继续读取旧视图；空 slot 保留普通语义。生成代码不增加运行库。

## Answer

为合格的普通根生成 executeValue；有合法缓冲通道时生成 executeBuffered 及静态 input/output 路径元数据。使用与内部函数一致的分析与生成实现，不复制一套优化判定。先由实际 Facts 操作生成物验证无重复前缀复制，再接生产消费者；本记录尚不表示 FlowState 已迁移。

## 单元素替换的表达能力缺口

ZX 目前只允许更新循环状态，普通函数不能直接更新传入列表的一个元素。作用域声明与活动状态切换需要这个原子操作；不能为绕过限制制造仅执行一次的假循环，也不能以 map 复制整列。

实现列表 `with(index, value)`：沿用现有非负 u64 索引与越界诊断，直接生成已有 ListUpdate IR。语法节点、IR 节点、所有权校验与缓冲复用均不新增分支种类；普通不可变调用保留值语义，唯一消费路径复用已有 ListUpdate 优化。它是通用列表操作，不针对 FlowState 放行。

作用域迁移尝试 grit 的 Step 导入改写规则，工具报告 Processed 0 files；ZX 后缀不被其 JavaScript 文件选择器处理。后续使用受限脚本及逐个语义职责审查，不把零匹配当作迁移完成。

## RX 内联后未使用类型导致的错误优化边界

直接 ZX 原型的深层值入口可复用容量，但带 Return 的 RX 原子入口仍将 Facts/Refinement 装箱。实际追踪发现 RX 属性内联删除了环境 tuple 的表达式，却保留类型表中的 tuple 描述；旧 duplicates 检查无条件扫描所有类型，未使用的 `(input, output)` 环境把 State 判为重复路径。

仅把 duplicates 的根集合改为实际输入、输出、表达式和契约表达式的类型（包括内部函数），仍递归遍历每个根的全部路径。实际重复聚合、列表/Store/task/原生边界及引用比较保护保持；不解除真实别名的装箱。需用新 RX 生成物和已有引用身份专项验证此修正，不能凭直接 ZX 草稿推断 RX 入口行为。

还发现旧单 Call 入口隐式返回 void；新事实接口已在 RX 草稿加入显式 Return，正式切换时必须同步全部入口。

## 宿主容量绑定约束

宿主资源仅五个 std.ArrayList 与 started 标志，状态使用生成类型。按生成的 output 路径静态选择对应资源，并在编译期验证：每列均有合法通道，input 的根字段与 output 后缀逐项一致。缺少通道或列之间互换将编译失败，不能静默落到普通 allocator 分配并遗失所有者。OOM 后仍遵循停止分析并释放全部标准资源的边界。

只读 mark/typeOf/restore 以零字节 FixedBufferAllocator 调用值入口；成功不能依赖临时 arena。新的 ABI 草稿尚待生产接入后的 Zig 编译验证。
