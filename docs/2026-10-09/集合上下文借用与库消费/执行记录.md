## 实际覆盖

三种数据结构为 list、含 limit/payload 的 object、含 left/right/active 的 nested object。每种结构有空、一般、零值、重复、别名/重叠等五个上下文数据组合。四个方法分别为 map/filter/every/some，每个都通过 source 和 library 路径实际执行。

library 路径复用成熟 predicates 编译工具，执行 link→encode→decode，销毁提供者和编码缓冲后，通过独立消费者生成及运行；source 路径直接项目分析、IR 校验及模块生成。新测试没有复制 link/codec 总控，也没有引入 zxc 运行库或动态调度。

host.echo 每次执行只观察一次原始上下文并返回同一引用。每次 callback 同时核对原 object 指针、list/payload 基址、nested 两个基址与别名，以及实际元素、上下文数据与完整结果。原生观察函数只读计算和写静态记录，不调用 allocator。

每组值根实际运行六项：空输入仍借用一次；多个上下文与列表组合的值/指针一致；echo 错误阻止回调；每个可达 callback 错误与短路；同一 arena 后续成功及失败保留早先结果；4096 元素保留输入和一次上下文求值。独立 oracle 不读取生成源码或使用生成程序计算期望。

所有输入列表、context 字段、payload 内容与两端 canary 在执行后保持；nested 中同一列表别名和重叠片段的原始地址保持。map/filter 比较完整输出，every/some 比较 bool、访问前缀及次数。输入的测试快照仅用于独立核对调用者小数据，不在正式编译器复制类型表或状态。
