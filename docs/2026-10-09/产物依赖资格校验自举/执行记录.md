# 产物依赖资格校验自举记录

- **Intent：** 将依赖目标资格规则迁入 RX/ZX，消除正式材料化宿主中的自有拒绝规则。
- **Data：** Record 目标 union、roots/planning 现有布尔列消费者与 prepared 的唯一调用链。
- **Edges：** 允许 Source、Native、External，仅拒绝当前 artifact 记录中的 Compiled；不影响 compiled library 的分析/链接。seed 保持原规则。
- **Answer：** 单列目标种类、显式 RX 门禁和 ZX 原子集合谓词，跨 ABI 零复制借用，构建及限定专项验证。

## 实施

TargetKind 定义在共同 dependencies/model.zx。import_kinds 替代 import_native，宿主穷尽 union→enum 投影；未新增并行投影列。Native 根收集和模块规划共享这一列，仅在 Native 时执行原生匹配。

prepared/run 使用已有 borrow.slice 连接两个生成 ABI 的枚举切片；编译期核对 tag 类型、成员名及值，避免裸强转。roots.rx 显式调用 dependencies/allowed，覆盖所有记录 body 分支，成功才进入 select。宿主 compiled 分支使用 unreachable，表示前置已经验证的内部契约。

## 构建与生成反馈

首次构建因 native_dependencies 的导入顺序不合内置规则而拒绝；已用正式 zxc fmt 修正相关 ZX。最新生成过程成功，两个 ABI 都生成普通四项枚举，成员与顺序一致。正式宿主编译已经通过 borrow.slice 的枚举表示兼容检查。

资格谓词的生成函数使用普通 while 循环和栈上状态，allocator 未使用，没有描述符 create 或数组复制。证据保存于资格谓词生成核对.json；不把此结论推广到整个 artifact 处理流程。

提前拒绝可能改变资源分配顺序；若记录同时包含多种错误，也可能改变先报告哪项错误。对于仅违反依赖目标资格的记录，错误仍为 InvalidModule。
