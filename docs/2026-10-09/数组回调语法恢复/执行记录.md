# 数组回调恢复执行记录

## Intent：最终目标

保持惯常集合回调语法，用普通 loop 静态实现；保留已有引用身份、所有权和分配边界。

## Data：可用证据

单文件及分模块 plan 真实入口编译均通过。已有 reverse 所有权五种模式经源码和库两条路线通过运行。对象归约 nested_object 通过，但 field_call、root_call、checked、initial_call 的 child 引用身份断言失败。

失败产物在深层循环布局中将 child 解成裸值，输出时重新构造，丢失原始指针；原有 state_value 表示已具备 origin 保留能力，但 iteration 的 reference 返回模式将普通纯循环排除在此路径之外。

## Edges：边界与限制

不能删除身份断言，也不能将身份保留仅限定到归约方法。修复必须作用于符合既有布局和调用安全条件的普通循环。列表缓冲、重复别名与外部边界仍遵守已有 state_plan 资格。

嵌套捕获另发现一处作用域遗漏：内层 floor 阻止直接扫描最外层绑定。修正为当前词法层未找到后请求父捕获层解析，再捕获父层投影；不跨过原生 loop 的显式边界。

## Answer：本轮修复与待验收

允许 reference 返回模式在 local_calls 已证明时进入现有保留 origin 的 state_value 路径；前后边界使用既有 conversion，循环内部继续静态值表示。正在以同一组既有专项重新验证，不将首次失败记录覆盖为通过。

## 自我批判

仅生成通过没有发现深层布局重新物化导致的引用变化。必须以已有运行断言和真实调用链验收；尚未证明的捕获覆盖、错误集合与大数组分配上界不能视作完成。

## 通用计数循环的容量预留

修复引用保留后，11 种对象归约及五种 reverse 所有权模式均通过源码和库运行。既有 map_unique 大数组分配边界仍失败：2048 项有效载荷 16384 字节，实际累计分配 43304 字节。原因是 ArrayList 增长导致 arena 保留多次分配，并非二次遍历或 reverse 再复制。

新增优化只接受普通前置循环：初始计数为零，条件为计数小于稳定源数组长度，每轮计数加一且源引用不变，待构建列表初值为空。更新列仍须通过现有版本与别名证明；另外按真实 scope 顺序和 object 求值缓存累计更新次数，分支取上界，拒绝包含目标更新的嵌套循环，保证每轮最多一次单元素 push。所有分析依据 IR 字段索引和操作，不依据集合方法名、生成符号或用例。

容量提示读取已经求值并绑定的 initial，不重算输入。在首次实际追加时调用 ensureTotalCapacityPrecise，空源和全部过滤掉的源不分配。过滤输出可能在最终缩容时另有分配；不能宣称所有过滤只分配一次。非空初始列表暂不接受该提示，以免预先上界求和引入并非必然发生的溢出错误。

嵌套数组的既有 nested_map 运行结果通过，但实际产物仍每轮复制整个外层结果。原因是缓冲元素资格遗漏 list。将列表切片作为普通不可变元素槽纳入已有别名证明，并同步限定局部值布局只转换直接 object/tuple 元素，嵌套 list 保留普通 slice 表示；否则类型递归展开与实际转换不一致。此修复需要重新检查嵌套回调生成与运行。

## 保留边界

循环所有权仍用整体保守摘要，混合借用源与新建结果的对象可能把 result 一并记为 borrowed；后端缓冲仍独立证明别名，不能用此轮性能结果代替字段所有权不动点证明。错误集合仍沿用普通索引、push 和循环的保守规则。

普通循环的 legacy deep 表示在不符合 state_value 资格时仍需继续审查来源身份；本次确认并修复的是已有归约专项实际经过的路径，不声称所有深层循环布局均已审计。只读对象元素列表不强制进入 inline-list 布局，继续使用原布局与普通缓冲证明。

本轮恢复集合源码接口并完成这些既有专项；完整语言与 RX/ZX 自举目标仍未完成。集合分析与生成优化中的手写 Zig 也是后续自举待迁移职责。
