# 数组回调使用参考

## Intent：最终目标

以常规集合参数和词法捕获表达数组计算，由编译器静态展开为普通循环。

## Data：接口与行为

| 方法         | 回调参数                         | 结果                 |
| ------------ | -------------------------------- | -------------------- |
| map          | value, index, array              | 回调结果数组         |
| filter       | value, index, array              | 保留谓词为真的原元素 |
| every / some | value, index, array              | 短路布尔结果         |
| reduce       | accumulator, value, index, array | 最终累加值           |

只声明需要的参数前缀；index 为 u64。外层值直接按词法名字引用，内层同名绑定遮蔽外层绑定。

```typescript
values.map((item, index) => item + index)
values.filter(item => item > settings.minimum)
values.reduce((sum, item) => sum + item, 0)
values.reduce((sum, item) => sum + item)
```

reduce 省略初值时从第一项初始化、第二项开始执行回调，空数组返回 IndexOutOfBounds。every 与 some 对空数组分别返回 true 与 false。

## Edges：边界与限制

回调当前为内联表达式箭头函数，捕获实际用到的绑定，不产生堆闭包。数组与对象继续遵守不可变借用和生命周期约束。Task 不能被回调重复消费，Store 访问也不能通过捕获获得权限。显式 loop 的规则仍要求通过初始状态传数据。

非 reduce 方法接受可选第二实参并按顺序求值一次；它不再是 callback 的第二参数，箭头函数通过词法名字读取上下文。此接口不承诺 JS 的稀疏数组、动态 this 或原型系统。

当前迭代 IR 的返回所有权和错误集合仍有保守分类，不能承诺所有集合结果均为 owned 或所有谓词均无分配错误。代码生成会独立证明缓冲别名与复用；空初始输出、稳定数组界限和单次追加的计数循环可以延迟预留容量。未满足证明时保留一般循环路径。
