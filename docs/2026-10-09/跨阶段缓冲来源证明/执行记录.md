# 跨阶段缓冲来源执行记录

## Intent：最终目标

在不改变普通对象身份和函数 ABI 的前提下，让独占列表经过多个 RX 阶段持续复用，并推进类型提取的多根规划与原生模块扫描。

## Data：证据

- Capability 按函数拓扑计算 index_only / writable / forwardable；每个嵌套调用使用准确的 callee lane。
- 返回隔离复用 versions → facts.retains；所有返回路径的其他字段不得保存目标版本、旧版本或借用。未新增重复 may 输出分析。
- exclusive 在同一 Graph 中逐个生产者回溯，每层重新检查 Selection 与 Observers，最后必须到达 fresh 根；不会把输入路径不同当作实参独立。
- fingerprint v41 包含同一 Capability 摘要，调用者失效规则与生成决策共用数据。
- 普通指针出口 callBufferedPointer 按普通 function 生成，保留输入根直接返回；layout 消费者只解引用读取。临时 state/iteration 表示暂停 pointer 模式并恢复。
- 真实 initial RX 入口生成成功；initialize → roots 经 function_11_buffered_pointer 传递 mapping/order/origins 三条非空通道，roots → expand_native 经 function_22_buffered 传递上述三列与 selected 四条非空通道。每个 transferred_started 均为 true。
- initial 的整包输出通过强制入口 build-obj；分模块输出以 manifest 精确装载依赖，通过独立强制入口 build-obj，覆盖 callBufferedPointer 的跨模块签名。
- 既有缓存资格、资源释放、失败恢复专项各 3 项，共 9 项通过。
- 既有 iterate_calls 的 identity / child / pair / branch_return / tuple_identity / list_alias，在 source 与 library 两条路径共 118 项通过，覆盖零步、更新后的旧别名、长序列、分配失败和适用的容量约束。未新增测试用例，没有运行全量测试。

## Edges：边界与限制

- index_only 允许已有起点为零的 prefix 视图缩短，不证明完整分配长度；不得据此 free/realloc/扩容。
- 输出形状及纯、无 Store、无合同、无外部实现门禁保留。未证明的借用仍走普通值语义。
- 新类型规划已支持 roots 布尔掩码，按源类型索引递增访问；原生扫描按即时 mapping 单次前向扫描，不重扫前面的模块。
- initial 是依赖已验证源数据的内部模块；尚未替代正式 artifact/build 入口，也尚未完成 type imports、显式 native imports、函数导入、导出、body、stores 等后续阶段。
- 物化字符串仍借用来源；跨 arena 生命周期与末次交付尚待接入。不能把编译通过当作已移除 Workspace 桥。

## Answer：本节点交付标准

通用跨阶段证明、普通 ABI 缓冲出口、真实多根及原生扫描源码、完整草稿与生成物，以及已执行专项日志。本次常规 zig build -j2 --summary all 已成功，36/36 步骤通过，输出见正式构建结果.txt。Zig 格式检查与 git diff --check 通过。

## 自我批判

最初只检查后续阶段转移，漏看 initialize → roots 仍走普通调用。继续追踪入口揭示 pointer ABI 门禁，不能仅为消除复制改用 value helper 再装箱。独立审查指出根身份风险后，已撤回该路径并实现普通 ABI 出口；同时审查临时表示切换，避免参数布局混用。现有专项支持回归结论，但没有把它们说成完整自举或任意输入的形式化证明。
