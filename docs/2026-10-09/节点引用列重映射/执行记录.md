# 节点引用列重映射执行记录

## Intent：最终目标

将正式产物的类型和函数引用列重映射迁入 RX/ZX，保留源节点编号顺序和产物独立所有权，移除整张函数、原生映射表的 ABI 转换。

## Data：可用证据

`remapping/ids.zx` 实现编号列变换，缺失映射或越界返回 null。`columns.rx` 明确类型域计算、失败短路、函数域计算和结果汇合。`nodes/remap.zig` 只负责生成接口与错误集合转换。符号、Store、表达式的新引用列直接交给最终表；其他列由 `nodes/columns.zig` 按原生命周期复制，字符串保留深复制。

`prepared/root.zig` 借用规划器的函数和原生映射，删除旧 nullable 映射整表转换。`IdMap` 保留 indexed 和 planned 两种只读表示，兼容种子、联结、缓存、library 和 RX 共十处旧构造点。

架构图与数据流图见同目录执行计划。草稿同步正式源码，生成源码与专项命令保留在本目录。

## Edges：边界与限制

本轮迁移的是正式产物引用列的算法，不是完整 Nodes 或完整产物模块。节点结构复制、函数/原生元数据处理、外层产物调度仍含手写 Zig。RX/ZX 生成普通 Zig，沿用编译器既有 arena 与静态模块机制；没有增加运行库或动态调度。

生成的新数组在产物 arena 中存活，不转入临时 arena；规划映射只在提取期间借用。编号变换不等于数据无需分配：新引用列仍需构造，其他非引用列的独立所有权复制仍然必要。生成器当前对象物化开销也不能被本轮迁移视为已经消除。

## Answer：交付与验收

现有专项共 41 项通过：产物提取 6、无效产物 6、分配失败 2、混合产物 10、混合分配失败 3、Store 槽位 5、缓存往返 2、原生模块联结 4、编译库原生导入 3。覆盖源分析释放后的独立生命周期、列输入不变、类型/函数编号变化、错误路径、缓存重联结与原生描述符。

标准 `zig build -j2` 返回 0，真实注册并生成 artifact_remap 和 ABI，编译正式 CLI。签名观察与结果见标准构建结果.json：修复 configurer、generate-lexer、generate-parser 三个未签名辅助程序后完成。新增 ZX 为 28 和 14 行，diff 空白检查通过。

未新增测试、未执行全量测试、未调用浏览器。远端新增提交仅涉及测试和文档，提交前对齐该提交，生产编译器基线未发生变更。

## 自我批判

最初只搜索 zx/modules，遗漏了使用公开 ArtifactNodes 的 library/RX 构造点。只读审查发现后补齐，并扩大到 compiler/src 和现有测试的全范围调用检索。以后共享类型变更必须同时检查公开重导出。

grit CLI 在本环境连帮助都未能返回，未执行批量规则；仅对明确构造点做受限替换，不将工具失败描述成代码验证成功。标准构建遇到 macOS 未签名生成辅助程序时，仅验证并修复本次构建后代、本工作树缓存中的程序，再重启已终止的构建；其他会话进程不在处理范围。

仍保留旧路径是种子与调用兼容边界，不是最终自举状态。后续必须以节点元数据、外层编排及传递依赖为验收单位，不能根据新增文件后缀或本轮测试通过宣称完整自举。
