# 原生借用输入执行回归

## IDEA

- Intent：把原生值调用分类的覆盖推进到真实 Zig host 执行，验证借用输入、调用顺序、错误停止、重复调用与返回结果生命周期。
- Data：此前 35 项分类测试；当前 1d337446 的 detached reader 顺序版本修复；成熟原生引用 source/library 生成与真实 ABI 测试。
- Edges：字符串、数值列表、嵌套列表和可选字符串四类输入；不强加公开值的指针相等或固定分配次数。不把参数组合或重复模式计成独立 Test262 文件，不增加 Test262 审阅数量。
- Answer：独立 test-native-borrowed-runtime 目标，按 payload 类型分组的 ZX/原生资源，真实源码与编译库消费两条路径，Debug/ReleaseSafe 实际命名测试、完整产物与执行证据，英文提交并 push。

## 执行步骤

1. 分离 model、read、step、main：reduce 调用普通 step，step 调用 read；read 执行 first、echo、second、allocated 四个真实原生函数。
2. host 对真实输入计算校验值并记录调用序列；echo 返回借用值；allocated 注入实际失败分配。测试同时比较完整输出内容与输入快照，避免只凭摘要放过结构错误。
3. 使用独立夹具与明确的预期值覆盖空值、UTF-8、NUL、可选空值、嵌套空行、等值独立所有者，以及空 reduce、种子、增长和重复调用。
4. 在每个原生错误点停止，在每个失败分配点核验清理和先前已逃逸结果；禁止后续原生调用越过错误。
5. 编译库编码、解码并释放提供者及编码输入，再消费统一库并生成真实可编译 Zig；保留两路生成产物。
6. 冻结独立检出，检查门禁和本次 diff；实际生产缺陷才通知指定实现会话。

## 初始自我批判

分类为 local 不等于无副作用承诺，因此测试记录每一个真实 native 调用。校验值可能碰撞，必须同时比较返回 payload 全部内容、空值状态及输入全部存储。生命周期测试不释放仍被合法借用的调用者所有者；它重点防止后续调用覆盖已返回分数及产品。
