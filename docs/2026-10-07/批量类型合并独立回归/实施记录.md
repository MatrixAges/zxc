## 测试构造与独立预期

完整 Scalars 按公开 Scalar 枚举顺序真实追加；基础 family 有 9 个复合行，覆盖 optional、enum、native reference、error set、tuple、list、object、task 全八种非 scalar tag。两个 optional 的子类型不同，不把 tag 数和 row 数混淆。

噪声 enum 和 tuple 放在完整 family 之前，实际移动本地 ID。alias family 为 enum 和结构行增加 8 个新 ID，native Node 复用原 ID：重复 native 名字/owner 但不同 TypeId 无法通过独立 Program 的 native owner 约束，因此不伪造合法完整 IR 来宣称验证这种别名。每个源表通过公开 validateIr，native row 具有对应合法 NativeModule owner；source/external origins 是类型合并协议的身份元数据，没有借用包装层或动态注册表。

结果检查逐 tag 验证具体内容：enum 名字、所有成员与顺序；native 标签；error members；tuple 三个子 ID；optional/list 子 ID；object 四个字段名字与 remapped 类型；task result 和 errors。每个源 module 的 mapping 长度及 scalar identity 检查独立成立，并逐行比较两套 family 的应复用/应分离关系及精确结果行数、origins 数。

| 分类      | 新增独立声明 | 覆盖                                                                                                          |
| --------- | -----------: | ------------------------------------------------------------------------------------------------------------- |
| mapping   |           15 | 双顺序编号移动、同表/多表别名、不同 tag/后续 payload、task 两字段、空集合、单表映射、重新合并                 |
| nominal   |           15 | source/native/external owner 与 member、origin kind、声明标签区分，成员内容/顺序/长度和 enum/native kind 冲突 |

输入快照包含八列类型和五列 origins，字符串内容也深复制。成功和错误路径逐列比较快照；资源扫掠只作用于 merge allocator，输入构建和快照使用独立 std.testing arena。错误接受准确 OutOfMemory、ConflictingNominalType 或 MissingNominalOrigin；成功验证完整输出 graph。内存检查由既有 allocation_testing 支持和 std.testing allocator 执行。

所有权正例先验证 merge 没有修改输入，再将 source 类型及 origins 的所有数值列写成 255、其中所有非空动态字符串写成问号，释放 source arena，最后重新验证完整结果内容和 origin。预期来自原始常量契约和 copied scalar IDs；不读取已经失效的 source 指针作预期，也不以旧 seed 算法作唯一 oracle。

## 自我批判与续接

跨输入顺序仅保证同组图内容与来源身份，未承诺所有 canonical 数值 ID 顺序稳定。底层 Table.appendFrom 可以部分追加后报错，本组资源要求属于完整 merge API 的结果 arena 清理与输入不变，没有伪造内部事务回滚契约。

原生引用在本组仅作为类型及身份，不代表宿主对象的运行时借用、原生函数调用或具体来源解析都完成了测试。输入元信息足以验证 type_link.merge 的公开协议，不能以此证明任意完整 Artifact/Library/Program 通过全部其他规则。

模块提取使用真实 Analysis 的九 tag 组合、task 闭包与 native/source 名义来源，仍按提取边界分析留待下一部分。公开 extract 先收集根闭包、按全局 ID 升序 include；正常端到端成功不能独立证明内部深 DFS 或 task-errors 优先调度的每个分支。
