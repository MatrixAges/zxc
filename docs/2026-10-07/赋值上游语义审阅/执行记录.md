## Edges：边界与限制

JS 的 var 和环境记录改为显式类型化 loop state。原文第二种写法的未初始化绑定不能在 f64 中表现为 undefined，fixture 使用已类型化初值，再执行原普通赋值及复合赋值。登记为 adapted，保留所有数值断言，不声称验证了声明提升和 undefined 语义。

赋值表达式返回值、链式赋值、动态 ToPropertyKey/valueOf、getter/setter、with/eval 以及未声明变量等要求仍需单独推进。本阶段没有把更新后 return 改称赋值表达式，没有用 native 整数索引替代动态属性键转换。f32 是 zxc 自身特性覆盖，不冒充 JavaScript Number 精度。

这批新用例经过正常 CLI 生成普通静态 Zig，未新增生产运行库、解释器或动态加载机制。函数与编译库消费路线使用已存在的专项回归继续验证。
