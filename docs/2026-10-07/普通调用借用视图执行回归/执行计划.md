# 普通调用借用视图执行回归计划

## Intent：最终目标

补充近期普通调用借用别名、前缀视图和偏移视图机制的实际执行测试，同时加强这组测试的编译库消费边界。全量 Test262 与全部 zxc 特性的目标继续保留；本部分不新增 Test262 审阅，不用参数组合冒充上游文件覆盖。

## Data：可用证据

现有 detached_reader 提供可写 Cell、字符串字节及指针槽保留检查、连续调用、分配失败与全部内存释放检查。原有 reference 读取整个列表，尚未读取普通模块调用返回的严格前缀或带偏移的范围视图。现有 library 路线只解码后直接生成模块，不等同于新消费者通过公开接口导入编译库；native/borrowed_runtime 已提供可参考的真实消费者模式。

## Edges：边界与限制

扩展现有单一职责测试家族，增加两种 fixture 与专属七项语义/生命周期检查，不复制执行器和参考模型。前缀 reader 通过 pop 返回 `[0, length-1)`，长度不超过一时保留原列表；偏移 reader 通过 splice 的 removed 返回 `[selected, length)`；调用者追加后继续通过视图读取旧元素及逻辑长度，完整输出与独立列表模型比较。

编译库路线需先链接、编码、解码，再释放 provider、library 与原 bytes，并把 bytes 清零，随后分析真正导入公开 Input/Output 的消费者。生成产物仍为静态普通 Zig，不新增专用运行库。保持原有八种路线的执行证据，不能只验证新增路线就声称库消费改动无回归。

不预设借用视图的分配上界或性能结论；既有适合优化的八种 fixture 保持其原检查。新视图测试不套用未经证明的 bounded 指标。正式测试源码由无人值守测试目标授权；文档、草稿和证据集中于本目录。只在确认生产缺陷后通知实现会话。

## Answer：交付格式与成功标准

新增 prefix/offset 各七项具名检查，source 与真实 compiled-library consumer 两路线每模式共 28 项；全家族每模式 156 项。保存冻结输入 SHA、生成程序/ABI、实际编译与运行 argv、完整具名执行输出和分配失败证据。完成 self-review，核对原有修改保留，使用英文 Conventional Commit 并实际 push。
