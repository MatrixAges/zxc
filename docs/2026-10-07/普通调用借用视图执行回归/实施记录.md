# 普通调用借用视图执行记录

## Intent：最终目标

验证普通调用返回的真实借用前缀、偏移视图在后续追加与连续执行中的正确性，并把 detached_reader 的库路线升级为实际公开接口消费。

## Data：可用证据

正式范围为十个测试包文件：原 build、fixture、model、compile、shape，新增 views_test 与四个 ZX fixture。沿用现有可写输入、结果比较、分配失败执行器；七项新检查分别覆盖零 reduce、追加后读取旧视图、重复和零选择、空列表准确失败、大规模增长、非空连续执行的全部分配失败、空调用的全部分配失败。

前缀使用已有 pop 的第零结果，它是原只读切片去掉尾元素；长度不超过一时保留原切片。偏移使用 splice 的 removed 结果，genz 的 removed_only 路径返回原切片的带偏移区间。参考模型根据独立可变 Cell 列表计算被选值及视图长度，逐项验证完整输出；不是调用生成器来得到预期结果。

## Edges：边界与限制

准备阶段初稿误写了不存在的 `.range` API，查阅 list_operations 与 IR 契约后改用实际 pop/splice；未把未知操作当作生产缺陷。首次 formatter 将多个文件放入单次命令，CLI 拒绝该调用形状，随后按其单文件接口分别执行。两项均是本任务自身准备错误。

新视图检查不要求旧八种已定义的 bounded 指标。既有执行器仍检查所有成功、业务失败和 OutOfMemory 路径的输入保留及 arena 最终释放；本部分不声称具体分配量或性能保证。

旧 library 模式此前是解码模块后直接生成；当前会在 provider/library/bytes 清理后创建新消费者，经 `dependency` 的公开 Input/Output 与 run 导入再生成。必须验证全部旧八种模式，不能把两种新增模式通过当作整个消费链无回归。

## Answer：已完成验证

Debug 与 ReleaseSafe 均完成 92/92 构建步骤与 156/156 Zig 测试；每模式包含 20 路，新增 prefix/offset 的 source/library 各七项共 28 项。新增独立目标每模式另行实际执行 36/36 步骤、28/28 测试，未把重复执行增加到覆盖统计。

每模式逐一重放全部 20 个实际生成二进制，具名输出与对应 root.zig/views_test.zig 精确匹配。编译/执行 argv、二进制 SHA、实际生成程序/ABI/options/测试模块及输出原文均归档；同一路线的归档 Zig SHA 跨优化模式一致，source/library 程序 SHA 则逐模式不同。核验门禁同时检查十份正式输入和十一份原有修改保持 SHA。

旧八种模式继续验证完整值、输入及生命周期，其中 reference/reverse 的既有 bounded 项按原规则直接返回，不提供内存上界断言。这四个适用性返回包含在 156 项具名入口中；新增 28 项没有该跳过分支。未声称 156 项都是独立新增用例或全部包含分配上界检查。

目录审计保持 83,052 个 JSON，50,773 个上游原文件未审阅；本部分不变更审阅计数。未发现生产缺陷，未通知实现会话。最终提交与 push 以终端实际结果为准。

首次 Debug 构建停于 10 个库消费者的 MissingReduce 结构检查（41/92 步骤完成，未执行运行测试）。直接检查 prefix 的已生成源码：provider/source 有两个循环且位于 execute 之后，真实 consumer/library 有四个循环且都位于 execute 之前。旧 shape 仅检查 execute 后的文本，误报了辅助函数布局。此错误属于测试检查范围，不是缺失 reduce，也未向实现会话误报。

首次 ReleaseSafe 同样因旧 shape 检查范围而停于 41/92 步骤，10 个消费者失败，未执行测试。两次均已确认终止后才同步 shape 修正到工作区，保留准备日志和输入。修正保持 execute 存在与两个循环的要求，把搜索范围改为整个生成模块，覆盖前置辅助函数，不修改任何生产行为。

首次提交 7bfa4f24 后项目 format.mjs 仅调整 build/detached_reader.zig 和 shape.zig 的空行，严格 SHA 门禁拦截推送。保留全部格式化前日志、输入和产物清单，同步最终格式到工作区与草稿，重新执行完整家族及独立目标后再发布；该提交尚未推送，可正常 amend。以后冻结前应使用项目 format.mjs，而不只调用 Zig 原生 fmt。

最终格式复核：Debug 与 ReleaseSafe 均再次实际通过 156/156，独立目标分别通过 28/28；重新归档全部 40 路具名重放输出与生成物 SHA，门禁通过。后续 amend 只更新尚未发布的本部分提交，不重写任何已推送历史。
