# 表达式语义检查自举

## Intent：最终目标

将expression_rules的完整类型及引用规则迁入RX＋ZX，宿主只借用规范列并返回布尔值。覆盖全部表达式种类，不以ZX入口包装原生判定。

## Data：可用证据

基线2e65d3d5。原expression_rules.zig共334行，按表达式行、类型表、符号、Store与函数签名决定类型及先后引用合法性。所有三个受控调用点都从同一ExpressionTable读取当前index，故改为(program,index)直接读取规范列，不保留临时行摘要。

类型表固定scalar编号来自core/type_table/model.zig：void=0、bool=1、u8/u16/u32/u64=2..5、i32/i64=6..7、f32/f64=8..9、string=10。这是IR契约，不是用例特例。

## Edges：边界与限制

前置结构与类型表检查继续先于语义规则。保持任务类型只能由Task或Reference产生、先前表达式引用、唯一捕获/字段、可比较optional、整数幅值和精确f32限制。Store调用按原列子区间读取，不能为传入slice而复制数组。

原生float桥仅提供通用f64/f32转换及isFinite，不接收编译器类型或表达式，不决定语言规则。seed保留旧算法供引导。契约自身的禁用表达式规则、作用域及其它剩余Zig逻辑仍不算已迁移。

## 实施记录

所有36种表达式均通过新的expressions_check.rx入口进入ZX规则。按原子、访问、集合、对象、运算符、条件选择、调用、变换、列表操作、迭代、作用域和任务分组；可比较性单独沿optional类型链迭代。宿主validate改为(program,index)，原算法完整保留在seed_expression_rules.zig，仅引导构建选择它。

宿主借用ExpressionTable、SymbolTable、Stores和函数输入／输出／Store列；TypeTable与Functions只在栈上组成描述符。Store调用复用同一ZX校验，新增first/count读取扁平call_stores子区间，不创建切片副本。浮点narrow/widen/isFinite仍是通用静态Zig原语，不能声称消除全部原生依赖。

正式宿主入口（完整实现）：

```zig
const std = @import("std");
const ir = @import("zx").ir;
const options = @import("parser_options");
const borrow = @import("canonical/borrow.zig");

pub fn validate(program: ir.Program, index: usize) bool {
    if (comptime !options.generated_parser) return @import("seed_expression_rules.zig").validate(program, program.expressions.at(index), index);

    const generated = @import("generated_ir_expressions");
    const Input = std.meta.Child(generated.Input);
    const Table = std.meta.Child(@FieldType(Input, "table"));
    const Functions = std.meta.Child(@FieldType(Input, "functions"));
    const table = ir.TypeTable.borrow(Table, program.types);

    const functions: Functions = .{
        .input_types = borrow.slice(@FieldType(Functions, "input_types"), program.functions.input_types),
        .output_types = borrow.slice(@FieldType(Functions, "output_types"), program.functions.output_types),
        .stores = borrow.slice(@FieldType(Functions, "stores"), program.functions.stores),
    };

    const input: Input = .{
        .table = &table,
        .expressions = borrow.pointer(@FieldType(Input, "expressions"), &program.expressions),
        .symbols = borrow.pointer(@FieldType(Input, "symbols"), &program.symbols),
        .stores = borrow.pointer(@FieldType(Input, "stores"), &program.stores),
        .functions = &functions,
        .index = index,
        .orchestration = program.store_mode == .orchestration,
    };

    var storage: [0]u8 = undefined;
    var fixed = std.heap.FixedBufferAllocator.init(&storage);
    var arena = std.heap.ArenaAllocator.init(fixed.allocator());

    defer arena.deinit();

    return generated.execute(&arena, &input) catch unreachable;
}
```
