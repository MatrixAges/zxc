# 原生谓词上游审阅自我复核

## Intent：最终目标

确认新增映射保留完整核心断言，并区分真正原生短路、适配边界、重复执行和准备阶段工具错误。

## Data：可用证据

13 份锁定原文逐项读取并保留完整 SHA。官方 sta/assert harness 原样加载；原始代码在严格和非严格模式分别运行。计数同时包含普通 `assert(...)` 和 `assert.sameValue(...)`，包装后仍委托官方断言执行，合计 54 个原始断言。

27 个不同原始断言逐项映射到结果、实际 calls 或原输入元素；每个 native case 都检查实际 visited、可写输入与整块哨兵。上游输入不变的五项断言关联 expected.input，不拿新加的返回值和次数代替原断言。

原生宿主只按显式规则和真实调用次数计算 bool，不读取用例 ID。期望由 Node 的标准 every/some 计算，不复写一份遍历与停止算法。非单调元素值控制区分访问序号与元素数值。

源码与真正编译库消费者各执行全部用例；consumer 使用旧 provider 与编码字节销毁后的解码结果。原始 zig test 已实际执行，另以相同编译参数产出明确二进制并重放；不能把 --test-no-exec 的构建状态当作行为通过证据。

两个故意变异控制在首个决定结果后增加一次真实回调，bool 返回结果保持相同，calls 分别从 2 到 3、从 1 到 2。观察检查均拒绝变异，证明它不只判断最终 bool。

## Edges：边界与限制

本部分新增 8 份 adapted，增强已有 5 份 adapted；没有升级 equivalent。外部计数替代闭包副作用，部分停止观察以显式宿主序号适配 JS index，必须说明 ZX 没有额外 index/source/this 回调参数。index 参数本身为核心的相邻文件继续未审阅。

getter 不执行、原型元素、动态 length、稀疏洞及 array-like 接收器的关键断言没有被普通列表替代；这些文件没有自动标记排除或已适配。空数组原文的 void/零参数回调在不可达处适配为 bool 回调，并不证明支持该函数签名。

新增 173 个不同 JSON 用例，在源码与库消费者两路线形成每模式 346 次检查；重放属于复核，不再次计入独立用例数量。83,490 是登记总数，不能代表本部分执行了整个矩阵。仍有 50,760 个上游条目未审阅，完整目标尚未完成。

没有新增编译器实现或应用运行库。predicate_trace 仅是测试包内的 runner 种类，接入 test-runtime 和默认完整 test；显式 native 宿主只为测试观察提供静态模块。
