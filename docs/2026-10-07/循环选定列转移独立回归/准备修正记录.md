# 准备修正记录

## IDEA

- Intent：保留测试准备失败，避免将宿主类型错误当生产缺陷。
- Data：首次准备 Debug 原始日志；七个正式 ZX 均正常分析发射并通过形态门禁。
- Edges：不修改编译器，不改变值模型和错误预期。
- Answer：四份宿主 root 的 check 参数改为公开 program.Output。初值构造需要 std.meta.Child(program.Input)，结果读取则保留 object/tuple 的公开 const pointer，不能对 Output 机械去掉 pointer。

第一次结果尚未进入 runtime，不能记作执行通过。冻结工作区在进程 terminal 后同步修正，保留原日志，重新执行。

初次修正后七夹具实际 96/96 通过。自我复核发现尚无 primitive 列增长后 pop 缩短再转移，增加 shrink 普通夹具，仍用相同数学模型检查正确 prefix 和最终长度。八夹具终态以两个新缓存完整验证，首次行为日志另行保存。

八夹具两模式各 110/110 通过后，按源码支持范围复核，发现还缺直接返回 primitive 列的公开 slice ABI 观察。新增 direct 普通夹具，与返回 Frame[] 的 fallback 形成明确对照。其模型、零步和多调用/OOM 检查沿用成熟 root，不放宽任何已有断言。由于源输入变化，最终两模式使用新缓存验证九夹具。
