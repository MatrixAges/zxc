## 生成路径自我复核

当前 ownership.zig 的公开 execute 调用 function_56_value，再在循环内调用 function_55_buffered；该外层 value 循环保持 Machine 的值表示，没有每轮物化嵌套对象。其后出现的 create 位于循环结束后的缓冲写回，不能误报为每轮分配。

同文件另有 legacy function_56，其循环确实包含 value→pointer 物化；目前文件内只找到该函数定义，未发现调用。仅统计整份生成文件 create 或 dupe 的数量，不能证明运行路径的零成本性质。仍需沿各规则族的 buffered 调用核实实际分配、容量及数据身份；不得据此宣称零成本验收完成。
