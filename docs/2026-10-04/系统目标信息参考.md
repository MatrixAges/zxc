# 系统目标信息参考

## Intent：用途

使用 `std:os` 查询编译产物的 CPU 架构、操作系统平台与字节序。语义对应 [Node.js OS](https://nodejs.org/api/os.html) 的 arch、platform 和 endianness。交叉编译时，这些值来自目标配置；例如在 macOS 编译 Linux 应用，platform 返回 linux。

## Data：接口与示例

| 调用            | 参数 | 返回类型 | 返回值               |
| --------------- | ---- | -------- | -------------------- |
| os.arch()       | 无   | string   | 编译目标架构名称     |
| os.platform()   | 无   | string   | 编译目标操作系统名称 |
| os.endianness() | 无   | string   | LE 或 BE             |

```zx
import os from "std:os";

export type Input = void;

export type Output = { arch: string; platform: string; endianness: string; };

export default function (in: Input): Output {
  return { arch: os.arch(), platform: os.platform(), endianness: os.endianness() };
}
```

保存为 main.zx 后执行：

```sh
zxc build main.zx --out application
printf 'null\n' | ./application
```

本轮 macOS x86_64 的输出是 `{"arch":"x64","platform":"darwin","endianness":"LE"}`（JSON 字段顺序可能不同）。

架构名称映射：x86→ia32，x86_64→x64，aarch64/aarch64_be→arm64，arm/armeb/thumb/thumbeb→arm，loongarch64→loong64，powerpc64/powerpc64le→ppc64。其余目标返回 Zig 架构 tag，如 s390x、riscv64、wasm32。

平台名称映射：macos→darwin，windows→win32，illumos→sunos；Android ABI 返回 android。其余目标返回 Zig OS tag，例如 linux、freebsd、wasi、ios。这些额外 Zig 目标属于 ZX 扩展，不宣称都是 Node 支持的平台。

## Edges：边界与所有权

接口无 I/O、无环境变量访问，不查询正在运行的内核版本或真实硬件型号。架构表示二进制的目标架构；在兼容层或模拟器运行时，不代表底层物理 CPU。

返回字符串为静态只读数据。Zig 调用方不传 allocator，也不释放返回值。ZX 使用普通 string 类型读取。系统资源、可用内存、CPU 负载、主机名与进程控制仍需要独立的宿主能力，本次未提供。

## Answer：构建与已验证范围

应用可直接用 `--target` 交叉编译。库模式同样保存目标查询实现，Zig 消费方在最终构建中选择自己的 target。

```sh
zxc build main.zx --out application-linux --target x86_64-linux
zxc build main.zx --out library --mode lib
```

[库消费者示例](系统目标信息/库消费者/build.zig)通过 `dependency.module("library")` 导入发布库；将上述 library 目录放在消费者 build.zig 同级后执行 `zig build`。主程序调用 execute 并输出 JSON。

macOS 应用已运行并与 Node 对照；已发布库经 ZX 再构建运行。七个目标的底层 LLVM 编译输出包含各自正确的目标字符串，其中 s390x 为 BE。其他平台未实际运行。完整记录与自我复核见[实施计划](系统目标信息实施计划.md)。
