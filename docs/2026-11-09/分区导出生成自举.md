# 分区导出生成自举

## Intent：最终目标

将分区导出的导入声明、panic 绑定、符号命名和 comptime 导出调用从手写 Zig
迁入 RX/ZX。保持原有顺序、路径 stem 语义和全部生成文件，保留迁移后优化。

## Data：可用证据

迁移前 partition.exports 使用 Builder 逐项生成 exportAs 调用。上一完整冷构建
为 130.69 秒墙钟、198.43 CPU 秒、2141421568 B 单体峰、2149007360 B 树峰。
固定基线仍为 129.74 秒墙钟、216.03 CPU 秒、2075033600 B 单体峰、
2247294976 B 树峰，不随阶段重置。

## Edges：边界与限制

路径 stem 暂由 Zig 标准库计算；适配只构造借用字符串的行描述符，不复制字符串。
该描述符数组和 AST 传输仍是过渡边界，不宣称完整编译器自举完成。
循环仅更新窄列，不携带宽 Context；Context 在 publish 一次组装。
不新增测试用例，使用现有构建和回归；性能只测本次影响的生成路径及完整累计指标。

记录局部及固定基线累计时间与内存变化，最终统一提交推送所有变更。

## 实现与首轮证据

RX 显式连接 initialize、bindings、entries、publish。bindings 创建两个导入和
公开 panic 绑定，提前复用 exporter 的 AST 节点；entries 保持输入顺序，构造
函数成员、变体成员、符号字符串及调用；publish 最后追加 comptime scope。
空输入同样保留空 comptime scope，与原输出一致。

Source 字符串行实际 ABI 为只读指针数组。适配层分配行头及只读指针表，字符串
内容均借用输入。首次编译发现可变行切片与只读契约不匹配，显式限定 const 后
通过；未放宽 columns 的安全检查，没有按 ABI 不同增加猜测式兜底。

生成代码复核：符号插值只生成 std.mem.concat 的栈上片段数组与一份结果分配，
不是生成完整 Zig 语句的模板。两元素 u32 调用参数数组属于 AST 持久数据。
窄列更新保留托管列表元数据，完整 Context 仅在循环后创建，不引入逐轮前缀复制。

工具两轮构建均 21/21，通过新工具再生成得到相同二进制 SHA256：
`f2d72ba808c0e622502e4dafb4ef1177053adbd692ec6f985f57eef92677269b`。

同输入的 8065 份生成文件（仅排除工具指纹 .zxc-inputs）逐路径哈希全部相同。
一轮预热、三对交替测量，各工具使用独立函数缓存并强制实际生成 338 入口：
CPU 中位 4.58→4.57 秒、墙钟均 1.24 秒、RSS 中位 743161856→742801408 B。
差异很小，不声明稳定收益；性能证据位于忽略目录
`.zig-cache/cold-build-analysis/ownership-research/partition-exports/generator-isolated`。

## 构建与行为验收

正式 CLI 构建 43/43 步通过。现有 library_publish 入口检查 5/5、发布运行
检查 2/2，通过独立 ZX、Zig 消费者的发布与执行路径。未新增测试用例；未修改的

seed 探针用动态文件及变体参数实例化 partition.exports 并编译通过。9 个 Source
文件均通过正式 CLI 的 fmt --check 与 lint，3 个 Native 文件通过格式检查。

## 自我复核与剩余边界

本阶段迁移的是导出 AST 规则，不是仅给旧生成器添加 RX 包装。RX 展示四个阶段，
ZX 保留内部遍历及单项构造。正式路径不再调用旧 exports；旧代码仅在
parser_options.generated_parser 为 false 时用于初始 seed。

借用字符串不等于零分配：原生适配新增行头及指针表；AST 列、调用参数与符号结果
也仍有必要分配。局部测量未见退化，不能仅凭 zero copy 或静态链接作性能结论。
AST 导入、printer 及其他手写编译器职责仍需后续迁移，完整自举目标保持进行中。
