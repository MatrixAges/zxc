## 自我批判标准

不能把 void 类型的返回值、表达式语句或 tuple 求值替代 JavaScript void 的语义而宣称对齐。未绑定名应先发生 ReferenceError，副作用必须实际发生；不支持的动态契约须明确排除，不能用固定输出模拟通过。
