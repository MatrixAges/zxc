# 集合显式上下文执行记录

## Intent

通过普通语言能力消除类型引用映射的额外初始化遍历，保持静态编排、借用和无隐式捕获。

## Data

- 前端支持 map/filter/every/some 的可选显式上下文；IR 复用 initial 字段，按 kind 区分上下文与 reduce 初值，无序列化字段变化。
- seed 与 RX/ZX 校验同步参数数量、类型、表达式先后关系与 Task 禁止规则。
- genz 共用编译期 context 绑定 helper，在源列表后、分配和遍历前求值一次；未使用时生成 discard。带上下文 map 不进入 SIMD 快路。
- seed 与 RX/ZX 所有权实现同步非 reduce 借用、引用结果来源保留及 filter 来源边界；传递借用遍历补齐 map/reduce initial。
- children.zx 从零初始化加 loop 改为显式 context map。正式生成的 type_extract.zig 在循环前借用 workspace，执行一次 alloc(u32, len)，再以一个 for 填满结果；原列以 splice 范围视图读取。循环调用参数在栈上组装，无上下文数据复制。
- 生成产物 SHA-256：f4d0ae84f0dcfbee42c3e81da49f1b8f64734613863b9ac8ca7510f677c830b1。
- 初版遗漏 children.zx 的语义空行被自举格式门禁拒绝，已由内置 fmt 修正。
- 两位只读审计分别检查生成与资源边界、借用与传递来源；发现 Task 共享会允许重复消费后，已在前端和两套 IR 校验明确拒绝。

## Edges

map 引用结果仍保守保留源列表和 context 两侧来源；未实现按返回依赖精确区分。新语法的实际端到端使用来自类型提取 map，其他操作的上下文路径通过源码审查；未新增行为测试，不能把既有无上下文回归当成所有新组合的行为证明。SMT 与 FPGA 仍不支持集合 transform 的符号执行，本轮未扩大其能力。

专用提取 Workspace 的持久 mapping 与终端存储仍未完成自举。集合上下文不引入运行时闭包，但不代表整个编译器零分配或已完成自举。

## 自我批判

“参数标成 Borrowed”不能单独保证线性资源安全，Task 的消费规则必须另行核对。本次用明确的类型限制封住共享上下文入口，避免为了新增语法扩大整个任务所有权模型。保留引用来源精度和新行为验证的实际边界，不把静态审查等同于运行验证。
