# 类型提取引用结果执行记录

## Intent

以显式 ZX 引用结果替代提取 Workspace 中的可变输出缓冲。

## Data

- 删除 Workspace scalar/references、prepareReferences、extract 输入 Buffer 及对应构建依赖。
- ready 节点计算 first、second 与 remapped children，终端 appendType 仅按 source 类型解释并拥有化这些已计算参数。
- children helper 借用源列范围，一次分配新 u32 输出，loop 通过不透明 mapping getter 逐项写入。
- 快速生成确认 splice 返回原列切片，map 一次 alloc(u32, count)，后续只对新建输出使用 constCast 原地赋值，无复制或扩容。
- 直接消费循环 status，使终端传入动态列表后仍使用值布局状态；固定引用不构造一两个元素的堆列表，动态 helper 参数使用栈对象。
- 首版嵌套条件及捕获外部变量的 map 被编译器拒绝，已改为符合现有规则的数据流；没有放宽语言或测试规则。
- 正式构建生成的 type_extract.zig 不再导入 references；产物 SHA-256 为 edad01eb43f7ac07c7d2c210123a5bf06f725b2e33cbd2e3ebecbacc716b3c8d。
- 只读复核确认 TypeStorage.append 消费数值、不保留临时 children 或 scalar 栈地址；名称仍按原规则拥有化。

## Edges

动态输出先初始化再填值，存在两次 O(n) 遍历。读取仍依赖不透明持久 mapping；并非完全纯函数或完整 Workspace 自举。普通循环边界仍有小型元数据分配，不能声称整个提取零分配。
