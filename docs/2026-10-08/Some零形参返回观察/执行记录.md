## Edges：边界与限制

ZX 集合回调要求单元素形式参数，实际使用显式但未使用的 item，并调用通用宿主谓词。结果观察适配不意味着零形参 lambda、函数 length/arguments/this、index/source 参数、稀疏数组或完整 JS some 协议已支持，所以保留 adapted，不提升为 equivalent。

另两个候选 iii-3、iii-4 使用带 length=2、仅索引 0 的类数组与 Array.prototype.some.call。该协议有缺失索引和泛型调用，不能改成单元素稠密列表便宣称原协议通过。本轮没有登记它们。

此部分只覆盖新原例及完整既有谓词门禁，不替代未过滤根回归、全部语言特性或完整 Test262 对齐。执行提交为 12431932，发布父提交为 12431932，二者分别保存；期间主分支的新实现不纳入该固定执行的通过范围。原工作区 .DS_Store 与其他会话的变更按字节保留。

原文件只断言返回 true，不能套用此前 every 原例的两条断言或两次回调结论。本轮亲读原文、调整真实原文驱动并以名称核对 some 的首次短路，原断言与附加控制分开记录。
