# 接续范围

## Intent：最终目标

继续完成全部 Test262 审查与 zxc 特性覆盖，并收敛未过滤根回归中的真实故障。

## Data：可用证据

本部分针对旧完整回归的 Store IO、Process 入口和 iterate 顺序故障，执行结果与固定提交见执行记录。目录仍有 128467 个样本、50631 个未审查上游原例、811 个 adapted 原例；目录数不等于全部上游已对齐，也不等于全部样本已在当前完整根门禁执行。

## Edges：边界与限制

尚需逐项核对旧全量中的 type views 夹具编译失败、前端对象消费与嵌套归约资源边界是否在更晚源码成立；此前独立修复回归和 scanner/compiler 复验已有各自证据，不能自动等同当前未过滤根门禁全部通过。完整根门禁中的冷构建 180 秒超时仍须单独调查，不因热缓存局部门禁通过而删除这一观察。

长门禁使用固定检出；先记录真实执行提交、输入哈希和会话句柄，再启动。执行期间保持该检出源码不变，主检出的其他工作可以继续。将命名测试、内部情景、构建步骤与缓存统计分开。只将当前已复现的生产缺陷发送给指定实现会话。

## Answer：交付格式与成功标准

下一部分优先执行对应未覆盖的原门禁，保留实际终态与 source identity，然后继续增加有真实上游断言依据的测试。每个完成部分用英文 Conventional Commit 提交并 push。所有部分完成后仍需按完整目标审计，不能用局部通过宣称生产级目标达成。
