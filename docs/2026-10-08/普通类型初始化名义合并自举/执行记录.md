# 普通类型初始化名义合并执行记录

## Intent

将普通类型初始化后的共享身份规范化迁入 RX，并统一普通与原生入口的终端提交边界。

## Data

- 外层 semantic/resolve.rx 调用 resolving/resolve.rx，仅 initialize、shared 与空诊断同时成立才调用 normalizing/normalize.rx。
- host/model 从包装 Input.request 获取原 Request；Context/Source/Snapshot 形状保持，导入 aliases 和已解析名称继续借用原快照。
- generated types/resolve.zig 不再调用宿主 shared_types；旧算法只供 types/resolve_seed.zig 经 shared_seed.zig 使用。
- 原 native/commit 迁到 semantic/resolving/host/commit，原纯类型提交保存在 delta.zig；普通结果传真实 id，原生结果显式传零。
- source/native/external origin 编码与旧契约相同；预留容量并复制 origin 后才提交类型，最后无失败追加来源。
- external origin 复制对已分配 module 增加 errdefer，覆盖 member 分配失败。
- 已检查生成 type_resolution.execute：真实存在 initialize/shared/diagnostic 分支；全部 imports 仅 std、integers、zxc_standard、zxc_abi，没有合并或来源 Writer。

## Edges

- 旧 resolved/aliases 指向 base，不参与新增 ID 映射；新 cache/result 在规范化后才提交。
- named/node 请求维持原行为，不自动规范化或补登记来源。
- 诊断在提交前拥有化，失败不发布新的类型/cache；seed 失败内部状态不因此宣称完全一致。
- 类型、缓存和来源容器的终端管理仍为 Zig；通用模块联结、缓存恢复仍有其他待迁移路径。
