### 历史 type views 失败

旧完整 ReleaseSafe 的实际错误是 graph.zig 在 `for (program.symbols)` 中把 SymbolTable 当切片遍历，导致 type-resolution-views 无法编译。当前夹具使用 count/at 列接口，不需要再修正。原 views 的九项检查在两个模式通过，覆盖 native AST、indexed Program、Expression 注解、精确别名深度边界和 native interface。

这证明该固定版本的原 type-resolution 门禁可构建执行，不把所有 type views 行为或所有 IR 列边界扩大为已完成。
