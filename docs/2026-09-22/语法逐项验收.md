# 语法逐项验收

## Intent：最终目标

逐项列出当前实现的 ZX 语法，便于核对原始要求。以下片段互相独立，不应连在一起执行；完整可执行案例在 packages/compiler/tests/runtime/cases。

## Data：语法与实现证据

### 1. 匿名入口与输入输出契约

```ts
export type Input = u64;

export type Output = u64;

export default function (in: Input): Output {
  return in + 1;
}
```

Input/Output 可以是标量或复合类型；Input=void 的项目函数允许无实参调用。

### 2. 纯类型文件与别名

```ts
export type Count = u64

export type Counts = Count[]
```

支持纯类型文件独立编译；重复声明与递归类型别名拒绝。

### 3. 标量

```text
bool
u8 u16 u32 u64
i32 i64
f32 f64
string
void
```

固定宽度，不做隐式变量位宽转换。整数形式字面量转为浮点上下文时必须精确可表示，与 Zig 一致。

### 4. 结构对象

```ts
export type Point = { x: f64; y: f64 }
```

字段必须完整、类型匹配；可选字段可省略。字段顺序不影响结构类型。

### 5. 枚举

```ts
export enum Mode {
	On,
	Off
}
```

成员是编译期固定值；支持 Mode.On 和枚举 switch。

### 6. 可选类型与字段

```ts
export type Value = u64?

export type Record = { value?: u64 }
```

使用 null 表示缺失；无类型上下文的独立 null 拒绝。

### 7. 列表与嵌套类型

```ts
export type Matrix = u64[][];

export type OptionalItems = u64?[];

export type OptionalList = u64[]?;
```

后缀按源码顺序组合，不混淆“元素可选”与“整个列表可选”。

### 8. 显式元组

```ts
const pair: [u64, bool] = [1, true]
const [value, enabled] = pair
```

位置数量与每项类型严格匹配；元组不会暗中变成第一项。

### 9. const 与局部标注

```ts
const count = 1
const limit: u32 = 20
```

不支持 let、var、重新赋值、++、-- 或复合赋值。

### 10. 解构与丢弃

```ts
const [next_items, _] = items.push(3)
```

每个返回槽都必须出现；void 业务槽必须用 `_` 丢弃。

### 11. if / else / else if

```ts
if (in.enabled) {
  return 1;
} else {
  return 0;
}
```

条件必须 bool，分支有独立作用域，非 void 输出要求所有路径返回。

### 12. switch

```ts
switch (in.mode) {
  case Mode.On: return 1;
  case Mode.Off: return 0;
}
```

支持 enum、整数、bool、string；重复标签和重复 default 拒绝。case 无隐式贯穿，不需要 break。

### 13. return

```ts
return value
```

void 输出也允许 `return;`。终止路径后的不可达语句拒绝。

### 14. 对象字面量、简写和展开

```ts
const next = { ...in.state, count: in.state.count + 1 };
const output = { next };
```

后面的字段覆盖前面的字段。操作数按源码顺序求值一次；不因为字段被覆盖而跳过其求值。

### 15. 列表字面量

```ts
const values = [1, 2, 3]
const empty: u64[] = []
```

元素同类型。空列表需要元素类型上下文。

### 16. 成员、索引与长度

```ts
in.state.count
in.items[0]
in.items.length
in.name.length
```

索引越界运行失败；length 为 u64，字符串长度按字节计算。

### 17. 算术

```text
+ - * / %
```

整数除法向零取整，余数符号随被除数。数值边界与严格浮点约定见 IR 契约。

### 18. 比较与逻辑

```text
== != < <= > >=
! && ||
```

bool 不转为数字。字符串相等按内容；对象和列表没有隐式深相等。

### 19. 条件表达式与空值回退

```ts
const selected = in.enabled ? in.left : in.right;
const amount = in.amount ?? 0;
```

逻辑、条件与空值回退均短路，不执行未选择分支。

### 20. 字符串与模板

```ts
const label = `hello ${in.name}: ${in.amount}`;
```

支持标量插值、嵌套模板和转义；诊断使用原文件字节位置。

### 21. map

```ts
const doubled = in.items.map((item) => item * 2);
```

回调是无捕获表达式，不可保存或返回。

### 22. filter

```ts
const selected = in.items.filter((item) => item > 2);
```

回调结果必须 bool。

### 23. reduce

```ts
const total = in.items.reduce((sum, item) => sum + item, 0);
```

必须提供初始值。初始值在回调外求值，不因此成为回调内可见的捕获变量。

### 24. clone

```ts
const owned = in.items.clone();
```

只在需要独立所有权时深复制；普通读取不复制。

### 25. push / pop

```ts
const [next_items, _] = items.push(3)
```

```ts
const [remaining, popped] = items.pop()
```

两个片段独立。操作消费旧所有者，pop 空列表时业务值为 null。

### 26. sort / reverse

```ts
const [ordered, _] = items.sort()
```

```ts
const [reversed, _] = items.reverse()
```

独占存储可以复用，旧绑定失效。

### 27. concat / splice

```ts
const [combined, _] = items.concat(other)
```

```ts
const [updated, removed] = items.splice(1, 2, replacement)
```

splice 的 start/count 必须在范围内；当前两个操作分配结果列表。

### 28. 类型、枚举与函数导入

```ts
import type { Record } from './types.zx'
import { Mode } from './types.zx'
import calculate from '../calculate.zx'
```

支持 ./、../、@/；所有导入参与环检测，包括未使用导入。类型与枚举来自纯类型文件。

### 29. 项目函数调用

```ts
return calculate(in);
```

调用与被调方的 Input/Output 连接。普通项目函数不能自行获取调用者 Store 能力。

### 30. 注册的原生纯接口

```ts
import clamp from 'lib:clamp'
```

只有宿主显式注册并审查的接口可用。注册签名可以将 tuple Input 展开为固定位置实参。后端处理同形 Zig 结构类型转换，保留符合 ABI 的切片引用；需要布局转换的列表会分配目标元素。

### 31. Call 注入 Store getter

```ts
const current = $store_v.value
```

句柄由 Call 注入，不写 `const $store_v = ...`；未注入、越权和回调捕获均拒绝。

### 32. Store setter 与读取暂存值

```ts
$store_v.value = { ...$store_v.value, count: $store_v.value.count + 1 }

return $store_v.value.count
```

只允许完整 Object 替换。成功后统一 commit；计算失败不 commit。发布的本地所有者被冻结为只读。

### 33. 命名与 AST 格式化

变量 snake_case，函数导入 camelCase，类型 PascalCase。解构与回调参数也检查。fmt 按 AST 语义块调整空行，保留注释和 Token，不以文本关键字匹配分组。

## Edges：明确不开放的内容

数据库、闭包捕获、用户泛型、一般循环、类、普通字段/索引写入、任意运行时 I/O、动态 import 不开放。Store 持久化与多对象原子发布属于宿主 Runtime 实现，不是编译器模拟的数据库。
