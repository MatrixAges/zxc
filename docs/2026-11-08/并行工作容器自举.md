# 并行工作容器自举

## Intent：最终目标

迁移 RX Parallel 的完整 worker 类型构造，包括 allocator/input/result 字段、
`run(self)` 参数、结果赋值方法和最终容器。生成普通静态 Zig，保持原 ABI。

## Data：可用证据

起点 `7da52412`。`zx/parallel/root.zig::workerType` 只构造结构化 AST；没有
递归 Lower.expr、fresh 或线程执行。它依赖既有类型表达式和函数引用服务。
同步 allocator、字段、赋值、函数和容器的 Source AST 能力已可复用。

## Edges：边界与限制

- 输入、输出类型和函数引用先由既有服务物化，随后读取全局 AST 基址。
- 结果字段保留 anyerror 联合；run 为 void，调用不 try，错误留在 result 中，
  由父级 join 后处理。不得提前传播错误或改变线程汇合顺序。
- 参数仍为 allocator/input 字段引用，无输入值复制或动态调用层。
- 父级参数求值、线程启动、join 与结果绑定仍为原生过渡依赖，不称整个 Parallel
  已完成自举。任务 worker 属于另一条路径，本阶段不修改。
- 不新增用例；复用现有 RX Parallel runtime/library 及生成对照。

## Answer：交付格式与成功标准

```mermaid
flowchart LR
    Handles[输入输出类型与函数引用] --> Fields[Source 字段构造]
    Fields --> Body[Source 调用及结果赋值]
    Body --> Method[Source run 方法]
    Method --> Container[Source 容器]
    Container --> Import[通用 AST 导入]
```

```mermaid
flowchart LR
    Worker[已初始化 worker] --> Run[线程调用 run]
    Run --> Call[传入 allocator 与 input 引用]
    Call --> Result[保存成功值或错误]
    Result --> Join[父级汇合后处理]
```

前后产物及 memo、自编译不动点、既有应用回归与固定累计性能验收后提交推送。
文档区分源码迁移和剩余原生依赖，不以局部不动点替代最终自举审计。

allocator、input、result；方法只有把非 try 调用结果赋给 self.result 的一条语句。

### 自我复核与剩余边界

worker 字段、调用、赋值、方法、容器的规则与构造已迁 Source；Native 没有依据
Source 操作码重放旧逻辑。静态文本借用，非文本嵌套 payload 在 scratch 结束前
取得目标存储；实际输入仅以字段引用传递，生成应用代码一致。

类型与函数引用服务、Native AST 存储及通用导入器仍是过渡依赖。父级 Parallel
参数求值、线程启动、join、结果处理及 Task worker 尚未因本阶段完成而自举。
完整目标仍需继续迁移、传递依赖审计和约定的三代自编译。
