## 类型与输入

普通 ZX 的 Input 组合标量下标、嵌套对象、二元组、枚举列表及可选标量；使用 try 捕获列表访问，返回捕获结果或正常枚举成员，使有限错误集物化成类型值。源代码没有新增运行时设施。每次先由生产分析、提取或链接、编码生成正常基表；变换按实际 kind 找到行，不假设类型行编号。

损坏边界包括四类列长度不配对、未知 kind、固定 Scalar 身份与保留列、非法标签、自引用或 void 子项、对象空字段名与无序字段、三个辅助列族的非连续范围或超过可用范围的长度、枚举空名与重复成员、错误集空成员。夹具先确认所需 kind、范围与成员确实存在，失败时不会退化为跳过测试。

库的既有 envelope helper 使用兼容的 v1 标记，而生产 encode 输出 v2。本轮正向对照将完整原始 payload 通过相同 helper 重新封装并实际解码；因此损坏输入与正向输入共享标记、摘要算法及 payload 形状，只改变指定列契约。缓存也通过同一封装对照。
