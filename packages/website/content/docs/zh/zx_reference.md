本页汇总语法与行为。完整函数示例见[编写逻辑](/docs/write-logic)。

### 文件契约

| 文件种类   | 内容                                            |
| ---------- | ----------------------------------------------- |
| 可执行文件 | 导入、导出的类型/枚举，然后是唯一的匿名默认函数 |
| 纯类型文件 | 至少一个导出的类型/枚举，没有可执行默认函数     |

可执行入口使用 `Input`、`Output` 与参数名 `in`。导入的可执行函数接收一个输入值。函数导入使用 `camelCase`，局部值使用 `snake_case`，类型使用 `PascalCase`。

ZX 不使用分号；代码中的显式 `;` 会报语法错误。使用换行分隔语句，块末尾可直接使用 `}`。对象类型的字段使用逗号或换行分隔。字符串和注释中的分号仍是普通内容。

### 值与表达式

| 结构       | 支持形式                                             |
| ---------- | ---------------------------------------------------- |
| 标量       | `void`、`bool`、各整数位宽、`f32`、`f64`、`string`   |
| 可选值     | `T?`、可选对象属性、`null`、`??`                     |
| 集合       | `T[]` / `Array<T>`、元组 `[T, U]`                    |
| 结构化数据 | 命名类型、对象、枚举                                 |
| 分支       | `if`、提前 `return`、条件表达式                      |
| 绑定       | `const`、元组解构、用 `_` 丢弃                       |
| 布尔运算   | 短路 `&&` 和 `\|\|`                                  |
| 字符串     | 按字节比较相等；支持的标量值可用于模板插值           |
| 复制       | `clone(value)`                                       |
| 转换       | `map`、`filter`、`reduce` 的不捕获外部值的表达式回调 |

### 不应假定的能力

不要使用 `let`、`var`、`for`、`while`、`throw`、通用闭包或用户自定义泛型。熟悉的语法不代表兼容 TypeScript，生成程序的底层也没有 JavaScript 运行时。

### 能力

`zig:` 和 `lib:` 导入需要宿主编译器集成显式注册外部能力。它们不是任意模块下载，也不代表 CLI 可以自动访问原生函数。Store 操作同样依赖宿主提供的编译与执行上下文。

### 运行时语义

数值位宽保持显式，无效算术和索引可能在运行时失败。列表修改操作消耗输入绑定并返回更新后的列表。类型检查通过，不能证明业务前置条件成立或宿主事务行为正确。

详细边界见[类型与值](/docs/types-and-values)、[集合与所有权](/docs/collections-and-ownership)和[当前编译器契约](https://github.com/MatrixAges/zxc/blob/master/packages/compiler/README.md)。

### match 表达式

`match` 包含两种模式：`match { ... }` 用完整布尔条件选择结果，`match value { ... }` 按目标值选择结果。`=>` 右侧是结果，`_` 是默认分支。

```typescript
const shipping = match {
  discounted >= in.free_shipping_minimum => 0,
  _ => in.shipping_fee
}

const label = match status {
  "paid" => "ready",
  "pending" => "waiting",
  _ => "blocked"
}
```

条件按源码顺序检查，只计算命中分支的结果。值模式的目标只求值一次，必须为非 void 标量或枚举。必须有唯一的末尾 `_` 分支，允许尾逗号，结果类型必须一致。逻辑与使用 `&&`。不支持区间、结构解构和链式比较。
