zxc はエージェント向けに設計されたプログラミング言語とコンパイラです。アプリケーションの構造と計算を分けて表現します。

- **RX**（`.rx`）：オーケストレーションと明確なモジュール境界を記述する XML。
- **ZX**（`.zx`）：静的に検証できるビジネスロジックのための、制約を持つ TypeScript 風の言語。

モジュールは一つの責務を持ち、ファイルパスで識別します。データは明示的な入出力を通じて境界を越えます。循環依存は拒否されます。

最初に[対応範囲と制限](/docs/capabilities)を確認してください。言語設計に機能が記載されていても、そのランタイムが実装済みとは限りません。
