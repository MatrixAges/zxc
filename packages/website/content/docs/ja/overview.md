zxc は **RX でビジネス構造を表し**、**ZX でアトミックなロジックを書きます**。データフローとデータ構成を明確にし、ビジネスが成長しても理解、追跡、保守を続けられることが中心的な目的です。

zxc はビジネス構造を RX に、アトミックなロジックを ZX に分けます。データの出所、通過する計算、行き先を境界と接続で明示します。コンパイラが依存関係を検査し、ビジネスの成長に合わせて構造上の制約を維持します。

### フラクタルな拡張

ZX の単位は、境界の明確な一つの計算を担います。RX がそれらをビジネスモジュールに組み合わせ、モジュールをさらに大きな境界へ組み合わせます。詳細化が必要なら内部を再び分割します。各階層で単一責務、明示的な入出力、一方向の依存を保つのが zxc のフラクタルな構成です。

「アトミック」とは責務と契約が明確な単位を意味し、データベースの原子トランザクションや最小断片を意味しません。「フラクタル」とは各階層で同じ分割・構成規則を使うことであり、循環依存や再帰呼び出しではありません。接続はデータが通る単位を、入出力型は境界上のデータ形状を示します。非循環性は依存の方向を制約しますが、すべての業務上の結合を除去するわけではありません。

### AI のコンテキスト

組み込みの依存解析により、ファイル、呼び出し、型の関係は検査可能な事実になります。このグラフを AI に直接提供し、関連単位の特定、上流と下流の追跡、変更影響の把握、必要なコンテキストの取得につなげることを目指します。

目標はトークン消費と認知負荷を最小限にし、明示的な契約とコンパイラのフィードバックによって、非 SOTA モデルも SOTA モデルと同じコード品質基準を満たせるようにすることです。

### 単位ごとの最適化

境界が明確な ZX 単位は、計算オペレーターのように解析し最適化できます。zxc の静的情報と Zig のコンパイル時機能は、インライン化、特殊化、抽象化コストの除去への道を開き、明快な業務表現と高性能を近づけます。

現在 ZX は Zig にコンパイルされます。Zig の LLVM バックエンドを選ぶ場合、対象プラットフォーム向けの最適化と機械語生成を利用できます。ゼロコスト抽象化は生成コードと測定で確認する目標であり、すべての操作に割り当てや実行時コストがないという意味ではありません。

長期的には、単位ごとの形式仕様と証明、アセンブリレベルの解析と生成、FPGA などのハードウェア対象への展開を目指します。形式検証には専用の証明ツール、FPGA には合成フローとバックエンドが必要です。LLVM が自動的に提供する機能でも、zxc がすでに実装した機能でもありません。

### 機能の範囲

現在の実装と実行可能な経路は[機能と制限](/docs/capabilities)を参照してください。設計目標を、公開済みのツール API や測定済みの性能結果と混同しないでください。

### 動く結果まで、一つの道筋をたどる

1. 計算、合成、ホスト機能のどれが必要かに応じて、[統合方法を選ぶ](/docs/choose-integration)。
2. [コンパイラをビルド](/docs/getting-started)し、既存の ZX サンプルを実行する。
3. 明示的な入出力を持つ[型付きロジックを書く](/docs/write-logic)。
4. ワークフローの境界を見える形にする必要が生じたら、[モジュールを組み合わせる](/docs/compose-modules)。
5. 実際のホストの能力に照らして[成果物を検証する](/docs/validate-and-deliver)。

### 共通の概念

| 概念               | 意味                                              |
| ------------------ | ------------------------------------------------- |
| モジュールの識別子 | 任意の名前ではなく、正規化されたファイルパス      |
| 入力 / 出力        | 計算の境界を越える値                              |
| 依存関係           | インポートやサービス呼び出しが作る静的な関係      |
| ケイパビリティ     | ホストが明示的に提供する操作や状態ハンドル        |
| 所有権             | どの束縛が値を消費または保持できるか              |
| ホスト             | 実行、メモリ、I/O、状態のコミットを担うプログラム |
