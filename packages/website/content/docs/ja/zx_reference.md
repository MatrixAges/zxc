### ファイルの契約

| 種類     | 内容                                                                  |
| -------- | --------------------------------------------------------------------- |
| 実行可能 | インポート、型/列挙型のエクスポート、その後に一つの無名デフォルト関数 |
| 型専用   | 一つ以上の型/列挙型のエクスポート。実行可能なデフォルト関数はない     |

実行入口は `Input`、`Output` とパラメータ名 `in` を使います。インポートした実行関数は一つの入力値を受け取ります。関数のインポートには `camelCase`、ローカル値には `snake_case`、型には `PascalCase` を使います。

### 値と式

| 構造         | 対応する形式                                                 |
| ------------ | ------------------------------------------------------------ |
| スカラー     | `void`、`bool`、各整数幅、`f32`、`f64`、`string`             |
| 省略可能な値 | `T?`、省略可能なオブジェクトプロパティ、`null`、`??`         |
| コレクション | `T[]` / `Array<T>`、タプル `[T, U]`                          |
| 構造化データ | 名前付き型、オブジェクト、列挙型                             |
| 分岐         | `if`、早期 `return`、条件式                                  |
| 束縛         | `const`、タプルの分解、`_` による破棄                        |
| ブール演算   | 短絡評価する `&&` と `\|\|`                                  |
| 文字列       | バイト単位の等値比較。対応するスカラーのテンプレート展開     |
| コピー       | `clone(value)`                                               |
| 変換         | `map`、`filter`、`reduce` の、キャプチャしない式コールバック |

### 前提にできない機能

`let`、`var`、`for`、`while`、`throw`、汎用クロージャ、ユーザー定義ジェネリクスは使えません。見慣れた構文でも、TypeScript との互換性を約束するものではありません。生成プログラムの下で JavaScript ランタイムが動いているわけでもありません。

### ケイパビリティ

`zig:` と `lib:` のインポートには、ホストのコンパイラ統合による明示的な外部登録が必要です。任意のモジュールをダウンロードしたり、CLI からネイティブ関数を自動利用したりする仕組みではありません。Store 操作もホストのコンパイル・実行コンテキストに依存します。

### 実行時の意味

数値のビット幅は明示的なままです。無効な算術や添字は実行時に失敗することがあります。リストを変更する操作は入力の束縛を消費し、更新したリストを返します。型検査の成功は、業務上の前提やホストのトランザクション動作の正しさを証明しません。

詳細は[型と値](/docs/types-and-values)、[コレクションと所有権](/docs/collections-and-ownership)、[現在のコンパイラ契約](https://github.com/MatrixAges/zxc/blob/master/packages/compiler/README.md)を参照してください。

### match 式

match 式には二つの形式があります。`match { ... }` は完全な真偽条件で結果を選び、`match value { ... }` は対象の値で結果を選びます。`=>` の右側が結果、`_` が既定分岐です。

```typescript
const shipping = match {
  discounted >= in.free_shipping_minimum => 0,
  _ => in.shipping_fee
};

const label = match status {
  "paid" => "ready",
  "pending" => "waiting",
  _ => "blocked"
};
```

条件は記述順に確認し、選ばれた結果だけを評価します。値モードの対象は一度だけ評価し、void 以外のスカラーまたは列挙型に限定します。末尾に唯一の `_` 分岐が必要で、末尾カンマを許可します。結果の型は一致する必要があります。論理積には `&&` を使います。範囲、構造分解、連鎖比較には対応しません。
