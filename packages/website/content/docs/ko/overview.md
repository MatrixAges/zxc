zxc는 에이전트를 위해 설계된 프로그래밍 언어이자 컴파일러입니다. 애플리케이션 구조와 계산을 분리합니다.

- **RX** (`.rx`): 오케스트레이션과 명확한 모듈 경계를 기술하는 XML입니다.
- **ZX** (`.zx`): 정적으로 검증할 수 있는 비즈니스 로직을 위한, 제약이 있는 TypeScript 유사 언어입니다.

모듈은 하나의 책임을 가지며 파일 경로로 식별합니다. 데이터는 명시적 입출력을 통해 경계를 넘고, 순환 의존성은 거부됩니다.

먼저 [지원 범위와 제한](/docs/capabilities)을 읽으세요. 언어 설계에 기능이 기술되어 있다고 해서 해당 런타임이 구현되어 있다는 뜻은 아닙니다.
