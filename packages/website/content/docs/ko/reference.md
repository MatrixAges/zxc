### RX 구성 요소

| 요소                        | 책임                               |
| --------------------------- | ---------------------------------- |
| `Module`                    | 일반 워크플로 파일의 루트          |
| `Call`                      | RX 서비스 또는 ZX 함수 호출        |
| `Task`                      | 관련 단계 묶음에 이름 부여         |
| `Parallel`                  | 독립적인 작업이나 호출 구성        |
| `Switch`, `Case`, `Default` | 분기 선택                          |
| `Return`                    | 워크플로 결과 반환                 |
| `Emit`                      | 외부로 보내는 비즈니스 이벤트 기술 |
| `Import`                    | 선택적인 구성 의존성 선언          |

`Task`는 다른 `Task`를 직접 포함할 수 없습니다. `Case`와 `Default`는 `Switch` 안에 둡니다.

### 파일 역할

| 파일           | 용도                       |
| -------------- | -------------------------- |
| `*.rx`         | 일반 모듈 오케스트레이션   |
| `*.zx`         | 타입이 있는 비즈니스 계산  |
| `*.gateway.rx` | Gateway, Group, Route 선언 |
| `*.store.rx`   | Store, Object, Field 선언  |

Gateway와 Store 이름은 비즈니스 경계를 나타내며, 일반 모듈의 파일 경로 식별자를 대체하지 않습니다. Store 별칭은 데이터 네임스페이스를 식별하며 모듈 별칭이 아닙니다.

### 컴파일러 명령

```sh
zxc input.zx --out output.zig
zxc fmt input.zx --check
```

로컬에서 빌드한 `zxc`가 `PATH`에 없다면 실제 바이너리 경로를 사용하세요. CLI는 현재 작업 디렉터리에서 `@/` 가져오기를 해석합니다. 일반 상대 가져오기는 가져오는 파일을 기준으로 해석합니다.
