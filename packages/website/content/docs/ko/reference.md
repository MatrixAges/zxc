### RX 어휘

| 구문                        | 책임                                 |
| --------------------------- | ------------------------------------ |
| `Module`                    | 일반 워크플로 파일의 루트            |
| `Call`                      | RX 서비스 또는 ZX 함수 호출          |
| `Task`                      | 관련 단계 묶음에 이름 부여           |
| `Parallel`                  | 독립적인 작업 또는 호출 구성         |
| `Switch`, `Case`, `Default` | 분기 선택                            |
| `Return`                    | 워크플로 결과 반환                   |
| `Emit`                      | 외부로 내보내는 비즈니스 이벤트 기술 |
| `Import`                    | 선택적인 구성 의존성 선언            |

`Task`는 다른 `Task`를 직접 포함하지 않습니다. `Case`와 `Default`는 `Switch` 안에 속합니다.

### 파일 역할

| 파일           | 용도                          |
| -------------- | ----------------------------- |
| `*.rx`         | 일반 모듈 오케스트레이션      |
| `*.zx`         | 타입이 있는 비즈니스 계산     |
| `*.gateway.rx` | 게이트웨이, 그룹, 라우트 선언 |
| `*.store.rx`   | Store, 객체, 필드 선언        |

Gateway와 Store 이름은 비즈니스 경계를 설명합니다. 일반 모듈의 파일 경로 식별자를 대체하지 않습니다. Store 별칭은 모듈 별칭이 아니라 데이터 네임스페이스를 식별합니다.

### 속성 계약

| 태그              | 필수 속성                             | 선택 속성 / 제한                               |
| ----------------- | ------------------------------------- | ---------------------------------------------- |
| `Module`          | 없음                                  | 이름 없음, 일반 `.rx` 루트                     |
| `Call`            | `in`, `fn` / `service` 중 정확히 하나 | `out`, `setter`는 `fn`과 함께만 사용           |
| `Import`          | `from`                                | 별칭 없음, 의존성만 선언                       |
| `Task`            | `name`                                | 비어 있을 수 없음, `Task` 직접 중첩 불가       |
| `Parallel`        | 없음                                  | 비어 있을 수 없음, `Task` / `Call` 자식만 허용 |
| `Switch`          | `on`                                  | `Case` / `Default` 자식                        |
| `Case`            | `value`                               | 같은 Switch 내 고유 값, 비어 있지 않은 본문    |
| `Default`         | 없음                                  | Switch마다 최대 하나, 비어 있지 않은 본문      |
| `Return`          | `value`                               | 리프                                           |
| `Emit`            | `event`, `value`                      | 리프                                           |
| 모듈 수준 `Store` | `from`                                | 선택적인 `as` 네임스페이스                     |

속성은 현재 구조 모델의 일부로 검증됩니다. `$in`, `ctx.result` 같은 표현식 문자열은 호스트의 해석이 필요합니다. 현재 RX 패키지는 이들을 파싱하거나 ZX와 대조해 타입 검사하지 않습니다.

### 검증 범위

이 패키지는 이미 구성된 AST를 검증하고 일반 모듈 경로를 등록하며 그래프 간선의 순환을 검사합니다. XML 로딩, 자동 반환 추론, ZX 연결, 이벤트 구독, 런타임 실행은 제공하지 않습니다.

예제는 [분기와 작업](/docs/control-flow)을 참고하세요. Gateway와 Store 루트에는 별도의 [선언 참조](/docs/gateway-and-store)가 있습니다.

### 컴파일러 명령

```sh
zxc input.zx --out output.zig
zxc fmt input.zx --check
```

`zxc`가 `PATH`에 없다면 로컬에서 빌드한 바이너리의 경로를 사용하세요. CLI는 현재 작업 디렉터리에서 `@/` 가져오기를 해석합니다. 일반 상대 가져오기는 가져오는 파일을 기준으로 합니다.
