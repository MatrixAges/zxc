ZX는 Zig를 생성하기 전에 구체적인 타입을 부여합니다. JavaScript의 단일 숫자 타입이나 암시적 형 변환 규칙을 사용하지 않습니다.

### 익숙한 타입 이름

| 소스 타입  | 기본 ZX 타입      |
| ---------- | ----------------- |
| `number`   | `f64`             |
| `boolean`  | `bool`            |
| `string`   | 불변 UTF-8 문자열 |
| `void`     | 출력값 없음       |
| `Array<T>` | `T[]`             |

`number`는 IEEE 754 배정밀도 부동소수점이며 안전한 정수 범위는 ±(2^53 − 1)입니다. 더 큰 정확한 정수에는 명시적 정수 타입을 사용하고, 금액은 적절한 경우 최소 화폐 단위의 정수로 나타냅니다. 이 이름들은 기존 타입을 재사용하며 값을 자동으로 초기화하지 않습니다. `bigint`, `symbol`, `any`, `unknown`, 동적 `object`, 독립적인 `undefined`, `null`, `never` 타입은 지원하지 않습니다. 값이 없는 경우에는 `T?`와 `null`을 사용합니다. 리터럴 추론은 바뀌지 않으며 JavaScript 암시적 형 변환도 도입하지 않습니다.

### 스칼라 선택

| 타입                      | 값                           |
| ------------------------- | ---------------------------- |
| `bool`                    | `true` 또는 `false`          |
| `u8`, `u16`, `u32`, `u64` | 지정된 너비의 부호 없는 정수 |
| `i32`, `i64`              | 부호 있는 정수               |
| `f32`, `f64`              | 부동소수점 값                |
| `string`                  | 문자열 데이터                |
| `void`                    | 값 없음                      |

경계에서 너비를 의도적으로 선택하세요. 기존 정수 변수는 암시적으로 넓어지지 않으며 부동소수점으로 바뀌지도 않습니다. 리터럴은 문맥에서 타입을 받을 수 있습니다. 문맥 타입이 없으면 양의 정수는 `u64`, 음의 정수는 `i64`, 소수 또는 지수 리터럴은 `f64`가 기본입니다.

### 구조화된 데이터 정의

```typescript
export type Input = {
  amount: u64
  label: string?
  adjustments: u64[]
}

export type Output = {
  amount: u64
  label: string
}

export default function (in: Input): Output {
  return { amount: in.amount, label: in.label ?? 'untitled' }
}
```

`T?`는 선택적 값이며 객체 속성은 `name?: T` 형태도 지원합니다. `T[]`는 리스트이고 `[T, U]`는 튜플입니다. 객체, 이름 있는 타입, 열거형을 사용하면 실행 전에 경계의 데이터 형태를 검사할 수 있습니다.

### 산술 가정 확인

정수 나눗셈은 0 방향으로 버림합니다. 나머지의 부호는 피제수를 따릅니다. 유효하지 않은 산술은 런타임 실패가 되며, JavaScript식 형 변환이나 자동 복구 값으로 처리되지 않습니다. 실패할 수 있는 연산 전에 비즈니스 전제조건을 검증하세요.

`&&`, `||`, `??`, 조건 표현식은 단락 평가합니다. 문자열 동등성은 바이트를 비교합니다. 리스트나 객체에 구조적 깊은 동등성 비교가 있다고 가정하지 마세요.

### 예측 가능한 이름 사용

값에는 `snake_case`, 가져온 함수에는 `camelCase`, 타입에는 `PascalCase`를 사용하세요. 실행 가능한 기본 함수는 익명이며 입력 매개변수의 이름은 `in`입니다.
