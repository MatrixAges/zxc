이 페이지는 구문과 동작을 간결하게 정리한 참조입니다. 완전한 함수는 [로직 작성](/docs/write-logic)에서 시작하세요.

### 파일 계약

| 파일 종류 | 내용                                                         |
| --------- | ------------------------------------------------------------ |
| 실행 파일 | 가져오기, 내보내는 타입/열거형, 익명 기본 함수 하나          |
| 타입 전용 | 하나 이상의 내보내는 타입/열거형, 실행 가능한 기본 함수 없음 |

실행 진입점은 `Input`, `Output`, 매개변수 이름 `in`을 사용합니다. 가져온 실행 함수는 입력 값 하나를 받습니다. 함수 가져오기는 `camelCase`, 지역 값은 `snake_case`, 타입은 `PascalCase`를 사용합니다.

### 값과 표현식

| 구문        | 지원 형태                                                                       |
| ----------- | ------------------------------------------------------------------------------- |
| 스칼라      | `void`, `boolean` / `bool`, `number` / `f64`, 정수 너비, `f32`, `f64`, `string` |
| 선택적 값   | `T?`, 선택적 객체 속성, `null`, `??`                                            |
| 컬렉션      | `T[]` / `Array<T>`, 튜플 `[T, U]`                                               |
| 구조화된 값 | 이름 있는 타입, 객체, 열거형                                                    |
| 분기        | `if`, 조기 `return`, 조건 표현식                                                |
| 바인딩      | `const`, 튜플 구조 분해, `_`로 버리기                                           |
| 불리언      | 단락 평가하는 `&&`와 `\|\|`                                                     |
| 문자열      | 바이트 동등성, 지원 스칼라 값의 템플릿 보간                                     |
| 복사        | `clone(value)`                                                                  |
| 변환        | 외부 값을 캡처하지 않는 `map`, `filter`, `reduce` 표현식 콜백                   |

### 지원되지 않는 가정

`let`, `var`, `for`, `while`, `throw`, 일반 클로저, 사용자 정의 제네릭을 작성하지 마세요. 익숙한 구문이 TypeScript 호환성을 보장하지는 않습니다. 생성된 프로그램 아래에는 JavaScript 런타임이 없습니다.

### 기능

`zig:`와 `lib:` 가져오기는 호스트의 컴파일러 통합에서 명시적으로 외부 등록해야 합니다. 임의의 모듈 다운로드나 CLI를 통한 네이티브 함수 자동 접근이 아닙니다. Store 연산도 호스트가 제공하는 컴파일 및 실행 문맥에 의존합니다.

### 런타임 의미

숫자 너비는 명시적으로 유지됩니다. 유효하지 않은 산술과 인덱싱은 런타임에 실패할 수 있습니다. 리스트 변경 연산은 입력 바인딩을 소비하고 갱신된 리스트를 반환합니다. 타입 검사 성공은 비즈니스 전제조건이나 호스트 트랜잭션 동작의 증명이 아닙니다.

상세 경계는 [타입과 값](/docs/types-and-values), [컬렉션과 소유권](/docs/collections-and-ownership), [현재 컴파일러 계약](https://github.com/MatrixAges/zxc/blob/master/packages/compiler/README.md)을 읽으세요.

### match 표현식

match 표현식에는 두 형태가 있습니다. `match { ... }`는 완전한 불리언 조건으로 결과를 선택하고 `match value { ... }`는 대상 값으로 선택합니다. `=>` 오른쪽은 결과이며 `_`는 기본 분기입니다.

```typescript
const shipping = match {
  discounted >= in.free_shipping_minimum => 0,
  _ => in.shipping_fee
};

const label = match status {
  "paid" => "ready",
  "pending" => "waiting",
  _ => "blocked"
};
```

조건은 소스 순서대로 확인하며 선택된 결과만 평가합니다. 값 모드의 대상은 한 번만 평가하고 void가 아닌 스칼라 또는 열거형이어야 합니다. 마지막에 유일한 `_` 분기가 필요하며 후행 쉼표를 허용합니다. 결과 타입은 일치해야 합니다. 논리곱에는 `&&`를 사용합니다. 범위, 구조 분해, 연쇄 비교는 지원하지 않습니다.
